# 01 项目总览

> 最后更新：2026-08-23

## 1. 项目目标

依据论文 [Retentive Network（arXiv:2307.08621v4）](../docs/paper/2307.08621v4.pdf) 从零手写
RetNet（未使用现成 Transformer/RetNet 模块），在本机（RTX 3070 8GB / i7-10700K / 32GB RAM /
Windows）上训练一个**中英角色扮演对话模型**。代码/数学/推理为「锦上添花」的加分项，主线是 RP。

## 2. 模型架构（手写实现）

- 位置：`retnet/model.py`，参数公式 `P ≈ 12·L·d² + V·d`
- 当前规模：**100.37M**（d_model=768，12 层，12 头，key_dim=64，value_dim=1536，ffn=1536，
  vocab=20000 byte-level BPE，输出与输入嵌入权重共享）
- 核心机制：Multi-Scale Retention（式 5-8）、多尺度衰减 `γ=1-2^(-5-h)`（固定 buffer）、
  xPos 相对位置（实数二维旋转实现）、每头独立 GroupNorm（Sub-LN）、三种前向范式
  （parallel 训练 / recurrent O(1) 推理 / chunkwise 长序列）
- 推理 state 体积：12×64×128 ≈ 2.4MB（bf16），O(1) 恒定——对比同规模 Transformer
  KV cache @4096 上下文约 151MB（详见 04 文档）
- 采样参数建议：T=0.7, top_k=40, top_p=0.9, rep_penalty=1.1, no_repeat_ngram=4

## 4. 完整训练历程

| 阶段 | checkpoint | 数据 | 步数/token | 结果 |
| --- | --- | --- | --- | --- |
| 1. 小模型验证 | `retnet_23m` | Wikitext-2 | 23.1M 参数 | val ppl 75.30，验证三范式一致 |
| 2. 英文底座 | `retnet_97m_wikitext103` | Wikitext-103（v16k 词表） | 97.6M 参数 | val ppl 50.39 |
| 3. 第一版对话 | `retnet_100m_chat` | 混合中英对话 57.9M token | 16k 步 | 会闲聊但很笨 |
| 4. 通用预训练 | `retnet_100m_pretrain` | FineWeb-Edu+中文 FineWeb+SmolLM 1.31B token | 200k 步 | val ppl 36-39，但忘了对话格式 |
| 5. 对话恢复 | `retnet_100m_chat_v2` | 对话恢复混合 82.9M token | 30k 步 | 找回聊天格式，回复偏短 |
| 6. 第一版 SFT | `retnet_100m_chat_sft` | 指令 SFT 36.5M（扁平打包） | 15k 步 | ppl 13.96 但**答非所问**（三个 bug，见 02） |
| 7. 对齐+掩码 SFT | `retnet_100m_chat_v3` | chat_pack_v3 194.7M token | 19k 步 | 回复 ppl 91.72，闲聊自然 |
| 8. 角色扮演 v1 | `retnet_100m_rp` | chat_pack_v4 217M（RP 37%） | 25k 步 | 回复 ppl 10.31，学会按设定说话 |
| 9. 继续预训练 | `retnet_100m_pretrain_v3` | pretrain_v2+旧语料池 4.06B，实吃 363M | 70k 步 | 新验证集 ppl 56.84 |
| 10. 角色扮演 v2（上版最优） | `retnet_100m_rp_v2` | chat_pack_v5 233.9M（RP 41%+口癖） | 35k 步 | 回复 ppl **8.25**；口癖遵循 4/5；多轮记忆 ✅ |
| 11. 长预训练（进行中） | `retnet_100m_pretrain_v4` | 池 4.06B，计划吃 2.66B | 520k 步 | 中途 ppl 52.7（LR 接近谷底） |
| 12. 角色扮演 v3（待跑） | `retnet_100m_rp_v3` | chat_pack_v8 225M（RP 42%，含文学对白） | 45k 步 | 链内自动评测 |
