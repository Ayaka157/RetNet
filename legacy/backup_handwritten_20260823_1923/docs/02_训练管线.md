## 1. 三种数据模式（train.py 自动识别）

| 模式 | 参数 | 用途 | 存储 |
| --- | --- | --- | --- |
| packed + masked | `--prepared_data_dir data_cache/chat_pack_v8` | 角色扮演 SFT | int16 2D 行 (N, 513) + 权重码 (N, 513) uint8 |
| shard 流式 | `--shard_dirs data_cache/pretrain_v2 data_cache/pretrain_merged` | 继续预训练 | int16/int64 扁平分片，mmap 流式，不占 RAM |
| 旧扁平缓存 | `--prepared_data_dir data_cache/chat_mix_v20k` | 早期数据 | int64 1D |

## 2. 关键设计：packed + 权重码（别改回去）

### 2.1 背景：第一版 SFT 为什么答非所问

`retnet_100m_chat_sft`（ppl 13.96）评测时答非所问。用贪心解码测试发现条件相关性
其实是好的（问番茄炒蛋答得对），真正的三个 bug：

1. **推理端**：`repetition_penalty` 惩罚了**提问里的词**，把回答推离问题；
   修复：默认只惩罚新生成的 token（`penalize_prompt=False`）+ `no_repeat_ngram_size=4`。
2. **数据未按样本对齐**：旧管线把对话拼成一条流再切 256 块，样本大多从对话中间开始，
   模型很少见到推理时真正的输入 `<bos>用户：…\n助手：`。
3. **loss 算在所有 token 上**：提问也参与训练，容量浪费在建模问题上。

### 2.2 现在的设计

- 每样本 = `<bos>[设定：persona\n]用户：{q}\n助手：{a}<eos>`，BOS 对齐、EOS 收尾，
  **截断保头**（保留对话开头）。
- 每 token 带权重码：0=padding（不算 loss）、1=助手回复（算）、2=提问/设定（`--prompt_loss_weight 0.1`）、
  3=纯文本回放（算）。
- 编码器唯一实现：`retnet/chat.py`（encode_dialogue / encode_prompt / encode_dialogues_batch），
  **训练与推理共用**，保证 token 边界一致。
- 打包：best-fit 装箱（`retnet/packing.py Packer`），padding 占比约 1.6%（v3 之前 16%）。
- 角色扮演 persona：`设定：` 块，prompt 权重，模型学「按设定说话」但不学「生成设定」。

### 2.3 推理端参数（play.py / eval 默认）

`--temperature 0.7 --top_k 40 --top_p 0.9 --repetition_penalty 1.1 --no_repeat_ngram_size 4`
—— 100M 模型采样别调太热，否则口语化跑偏。

## 3. 修过的坑（历史记录）

| 问题 | 原因 | 修复 |
| --- | --- | --- |
| PPL 锯齿（跌了又涨） | train_loop 每段把 cosine LR 当新周期重置 | train.py 新增 `--lr_total_steps`，train_loop 自动传全局总步数；续训读 best_model 防覆盖 |
| Windows 上 `--compile` 崩溃 | 无 Triton，Inductor 失败 | 自动检测：有 triton 用 inductor，否则降级 aot_eager；后已安装 triton-windows |
| `train_loop.py` 参数错误重试 5 次 | Windows 下 `--` 分隔符残留 + sys.path 缺项目根 | 自动去 `--`、加 sys.path、参数错直接退出 |
| 半角逗号污染（`地方,比如说`） | 中文语料夹杂半角标点 | `clean()` 中 CJK 间半角标点转全角（英文不受影响）+ `is_fragment` 碎句过滤 |
| 口癖合成 bug | `t_cold` rstrip 漏 `？`；`t_short` 未硬截断 | 修复 + 严格 ≤20 字截断 |
| PowerShell 5.1 跑含中文的 .ps1 报 ParserError | ANSI 编码读文件 | 一律用 `pwsh`（PowerShell 7）执行链脚本 |

## 4. 常用训练命令（详见 RUNBOOK）

```powershell
# 角色扮演 SFT（当前最优路径）
C:\Tools\Miniconda3\envs\AI\python.exe scripts\train_loop.py `
    --total_steps 45000 --segment_steps 45000 `
    --save_dir checkpoints/retnet_100m_rp_v3 --log_dir logs/rp_v3 -- `
    --prepared_data_dir data_cache/chat_pack_v8 `
    --vocab_size 20000 --d_model 768 --num_layers 12 --num_heads 12 `
    --seq_len 512 --batch_size 10 `
    --warmup_steps 1000 --lr 1.1e-4 --min_lr 1.1e-5 --prompt_loss_weight 0.1 `
    --mode parallel --amp bf16 --device cuda --compile `
    --init_from checkpoints/retnet_100m_pretrain_v4/model.pt `
    --eval_interval 2500 --eval_batches 40 `
    --chat_format --generate_prompt "你真好看"

# 继续预训练（int16 分片流式）
C:\Tools\Miniconda3\envs\AI\python.exe scripts\train_loop.py `

    --shard_dirs data_cache/pretrain_v2 data_cache/pretrain_merged `
    --tokenizer_path data_cache/chat_pack_v4/bpe_tokenizer.json `

    --seq_len 512 --batch_size 10 `

```

## 6. 训练链（long_chain.ps1）结构

1. Stage 1：继续预训练（520k 步，~26h）→ `pretrain_v4`
2. Stage 2：角色扮演 SFT（45k 步，数据优先级 v8→v7→v6→v5）→ `rp_v3`
3. Stage 3：自动跑 `eval_chat.py` → `logs/chat_eval/rp_v3_final.md`

每段 40k/45k 步重启一次（compile 约 90s 开销可忽略），train_loop 崩溃自动重试、断电可续。
