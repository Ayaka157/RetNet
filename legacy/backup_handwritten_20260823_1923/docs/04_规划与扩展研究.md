## 3. 架构扩展研究（已调研，未实施）

### 3.1 RetNet 之后的学术路线（线性注意力家族）

| 路线 | 代表工作 | 核心思想 | 对我们的价值 |
| --- | --- | --- | --- |
| 门控线性注意力 | Gated Linear Attention（ICML 2024） | 固定 γ → 可学习逐头门控 + 硬件 chunkwise 内核 | 直接改良：γ 可学习化 + chunkwise 训练解锁 |
| 选择性写入 | Gated DeltaNet / DeltaNet-2（NVIDIA） | delta rule：S = γS + β(kvᵀ - kᵀS) | 「记住用户信息/剧情节点」的正解 |
| SSM 统一理论 | Mamba-2（Transformers are SSMs） | SSM ↔ 结构化注意力对偶 | 理论坐标系 |
| 混合头小模型 | Hymba（ICLR 2025） | 半 attention 头 + 半线性头，专为 ≤1.5B 设计 | 小模型最优形态参考 |
| 神经长期记忆 | Titans（Google 2025） | 可学习记忆模块，测试时写记忆 | 长设定外部记忆（远期） |
| 开源社区 | RWKV-7 Goat | token-shift + 门控 | 社区路线参照 |
| 稀疏化（对照） | NSA（DeepSeek ACL 2025） | 硬件对齐稀疏注意力 | 长上下文对照路线 |

来源链接见 `05_数据源档案.md` 末尾「研究资料」。

### 3.2 推荐组合拳

- **A（首选）**：GLA 化——γ buffer → 可学习逐头门控 + chunkwise fused 内核（~80 行）
- **B**：DeltaNet 式写入门（~40 行改 MSR 状态更新）→ 角色扮演记忆
- **C**：Hymba 式混合头（2-3 头换 sliding-window attention，~100 行+重训）
- **E**：尺寸 100M → 150M（d896/L14）→ 222M（d1024/L16），net2net 函数保持生长
- 建议：A + E 短期，B/C 中期二选一；**都不影响当前训练链**，可随时开工

### 3.3 KV Cache 相关结论（重要）

RetNet **不需要 KV cache**：推理 state = 每层 12×64×128 bf16 ≈ 196KB，共约 2.4MB，
O(1) 恒定。对比同规模 Transformer：512 上下文 ≈ 19MB，4096 上下文 ≈ 151MB。
真正可做的是 **state 减肥**（GQA 式共享投影 / fp8 量化）。

## 4. CoT 可行性结论（已实测+调研）

- 100M 推理期 CoT 无效（实测：加提示词更乱）
- 有效下限：0.5-1B（需大模型蒸馏 CoT 数据）；可靠推理 7B 起；原始「涌现」区间 100B+
- 本硬件（8GB）：350M 需梯度检查点、500M 需 CPU offload，训 10B token 要 2-3 周，
  **性价比极低**；务实路线 = 用 API 蒸馏数据 / 云 GPU / 222M 时附带两步算术级 CoT
- 参考：[Wei et al. CoT](https://research.google/blog/language-models-perform-reasoning-via-chain-of-thought/)、[Teaching Small Language Models to Reason (SCOTT)](https://aclanthology.org/2023.acl-short.151/)、[Qwen2.5 边缘模型](https://qwenlm.github.io/blog/qwen2.5-llm/)
