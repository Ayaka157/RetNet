## 根目录关键文件

| 文件 | 说明 |
| --- | --- |
| `RUNBOOK.md` | 运维操作手册：所有训练/评测/数据命令、突发状况处理（与 02 互补） |
| `README.md` | 项目 README：架构原理 + 目录结构 + 快速开始 |
| `train.py` | 唯一训练入口（packed 掩码 SFT / shard 流式预训练 / 旧扁平数据三模式自动识别） |
| `play.py` | 交互推理：角色扮演（`--system`/`/set` 换设定）、闲聊、英文续写 |
| `retnet/` | 模型与数据核心：`model.py`（RetNet 手写实现）、`chat.py`（训练推理共用编码器）、`packing.py`、`flatdata.py` |
| `scripts/` | 数据下载/构建/挖掘/评测/训练链脚本（详见各文档） |
| `checkpoints/` | 各阶段模型权重（命名规则：`{规模}_{阶段}_{版本}`） |
| `data_cache/` | 全部语料与 token 缓存（只放 E 盘） |
| `logs/` | 训练日志、评测报告（`chat_eval/`、`capability_eval/`）、归档 |
| `docs/` | 本文档集 + `scaling_study.md`（放大理论研究）+ `paper/`（论文原文） |
| `legacy/` | 被取代的旧脚本（chat.py/generate.py/prepare_chat_corpus.py） |
| `tools/`、`qq_decode_work/` | QQ 聊天记录提取（另一条线，与本项目训练无关，勿动） |
