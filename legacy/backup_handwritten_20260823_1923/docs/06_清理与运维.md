## 4. 运维速查（详见 RUNBOOK.md）

- 查看训练：`nvidia-smi --query-gpu=temperature.gpu,utilization.gpu,memory.used --format=csv`
- 中断/续训：kill 后重跑同一条 `train_loop.py` 命令（自动从 last_model.pt 续）
- 睡眠防护：`powercfg /change standby-timeout-ac 0`
- 突发：OOM → batch 10→8；NaN → 从 best_model 恢复 LR 减半；断电 → 重跑同命令
