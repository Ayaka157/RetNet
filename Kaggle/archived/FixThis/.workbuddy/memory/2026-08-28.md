## final2-run1 复盘 → final3（torch_xla 官方 checkpoint）

- final2 上 TPU 实测：scan 崩溃消失（前向顺利进入第一个 block），新报错 `AttributeError: module 'torch' has no attribute 'xla'`，发生在 `torch/utils/checkpoint.py:93 _get_device_module` → `getattr(torch, "xla")`。
- 根因两层，皆框架侧：
  1. `torch.xla` 是 torch≥2.9 才有；Kaggle torch 2.7.x 没有。`torch.utils.checkpoint` 非重入路径无条件 `getattr(torch, device_type)` → XLA 上必炸；重入路径在新版 torch 同样调它，换参无用。
  2. pytorch/xla #7024：上游 checkpoint 在 XLA 上即便能跑也不省显存——XLA CSE 会把 backward 重算与原前向合并抵消。官方解法是 `torch_xla/utils/checkpoint.py`（重算输入打 `xm.optimization_barrier_` + XLA RNG seed 管理）；仅支持 reentrant（#8729）。
- 教训：**在 XLA 上不要自写 naive checkpoint**（会被 CSE 静默抵消），也不要用 `torch.utils.checkpoint`（torch<2.9 崩）——用 `torch_xla.utils.checkpoint`。
- 修复 T1/T2（已核对 r2.7 源码：`ctx.inputs` 保非张量参数、tuple 输出兼容、optimization_barrier_ + xm.fork_rng）：
  - cell-4 import：`import torch.utils.checkpoint` → `from torch_xla.utils.checkpoint import checkpoint as _xla_checkpoint`；
  - `RetNetBlock.forward`：调用换成 `_xla_checkpoint(self._block_forward, x, mode, state, offset, return_state, chunk_size)`（默认 reentrant）。
- 产物：`retnet-kaggle-train-8k-final3.ipynb`（相对 final2 仅 2 处 diff，全 cell 编译通过）。报告 §-2 已记录。
- 重要正面信号：§-1 的 scan 修复已实证生效（报错从 scan HLO 冲突推进到 checkpoint 调用，两个缺陷互相独立）。
