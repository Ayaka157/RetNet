## 四、必须采纳的两条**升级**（核查员的独立发现）

### 4.1 冻结的 γ 不是「假说」，是**已验证**

报告现在写「同一常数跨层重复出现，与'从未收到梯度'一致（假说，未验证）」。
核查员把它证成了：这些 γ（**0.5430**）远低于生长时初值（`1 − 2^(−5−h)` ≥ 0.999999），
说明它们被 **AdamW 解耦权重衰减**搬动过。按三段 `trainer_state.json` 的逐步 `learning_rate` 积分得
`Σlr = 6.1078`，`× wd = 0.1` ⇒ 预测 `exp(−0.6108) = 0.5429`，**实测 0.5430（差 0.02%）**。

⇒ 改写为：heads 16–21 是「**从未收到梯度、但被权重衰减推低 45.7%**」；
heads 12–15 的 0.4462 对应在 0.5B 之前多一段 `Σlr ≈ 1.96`。**给出积分式，去掉「假说，未验证」。**
