## 0. 结论（先给答案）

**不推荐换主干。** 现有手写 RetNet（272.30M，20 层，d1024/H16/value_dim 2048/ffn 2048/vocab 20000/seq 2048）
在 <1B 尺度上没有任何一个候选架构能给出一份「值得付 3 周重训代价」的实测优势；而所有候选都要
**从零重训**（权重不可迁移），并放弃 819M token 的预训练知识继承与 `GrowthLayerNorm` 生长线。

按性价比排序，**只值得做三件「加法」，不换骨架**：

| 优先 | 动作 | 依据 | 代价 |
| --- | --- | --- | --- |
| **A** | **混合化：把 20 层里的 4–5 层 MSR 换成 softmax attention**（保持 3:1–6:1 的 linear:full 比例） | 340M/20B 受控实测：linear:full 比例是 **recall** 的主控量，LM loss 对此几乎不敏感；DeltaNet 论文里「每两层插一层 SWA」或「只加 2 层全局 attention」就超过强 Transformer 基线 | seq 2048 下前向 FLOPs **+8~10%**（见 §4.3 估算）；需要给 `generate()` 新增一种推理 state（KV cache，仅这几层） |
| **B** | **GLA 化：把 per-head 标量 γ 换成 per-channel 数据相关门控**（唯一可**函数保持**的架构升级路径） | 门控/选择性写入是 340M 研究里唯一被反复点名的「有效设计轴」；且把 log-decay 初始化成 `log γ`、门控投影零初始化时，GLA 层在初始化处**恒等于**当前 MSR | 新投影 + `retention_fast.py` 的衰减表从 `[H]` 扩到 `[H,C,kd]`；估 300–600 行 / 3–7 天；**可继承现有权重** |
| **C** | **Delta 式写入门**（docs/04 的 B 方案）：给状态更新加一条零初始化的 delta 修正支路，针对「记住剧情节点」 | 第三代（delta rule）是唯一在 ppl 与 recall 上同时超过第二代家族的机制（DeltaNet→GatedDeltaNet→KDA 这条线） | 非函数保持；chunkwise 形式要重写；估 400–800 行 + 重训 |

**最被高估的架构：Mamba-2 / 纯 SSM。** 它的招牌数字（"2–8X faster"）是**内核/推理速度**，
不是「同算力下更强的语言模型」；而小模型上相对 Transformer 的 ppl 优势本来就接近 0，
recall / copying / 状态跟踪三项恰恰是它被反复测出更差的地方（§3、§5）。
第二被高估的是 **xLSTM**：只有原班人马的自报，没有找到独立的 <1B 复现，且不含在 fla 里、sLSTM 要自己写 kernel。

| C6 | 8GB 显存墙：最优配置是 batch 1 × accum 4 + 8-bit Adam + 关梯度检查点 = **714 ms/优化步（11,496 tok/s，等效 batch 4 @8192 token）** | `docs/15` §0、§3.1 |
| C7 | 项目**没有 `.git`**，换 kernel / 换架构没有回退路径 | `docs/11b` §3.2、§5.2 |
| C8 | 手写自研是实现的一部分（README：不使用现成 Transformer/RetNet 模块），因此「引入 fla 层」本身是一个项目决策，不只是技术决策 | `docs/01` §1 |

> C1–C3 是**好消息**：它们都是「模型前面的数据与损失接口」和「模型内部的三条前向路径」，
> 而任何线性注意力家族（GLA / HGRN2 / DeltaNet / Gated DeltaNet / Mamba-2 / RWKV-6/7）都同时有
> **chunked 训练形式**与**逐 token 递推形式**，所以 C1/C2 天然可复用，C3 只是「要写出第二、第三条路径」。
> C5 也与 mixer 正交（`GrowthLayerNorm` 只包住归一化）。
> **真正的成本是 C3 的两条额外路径 + 新 kernel 的正确性 + C4 的护栏缺失。**

## 3. 小模型（<1B）上相对 Transformer 的实测证据

### 3.1 最相关的一份：340M 受控 × 72 个模型

**《A Systematic Analysis of Hybrid Linear Attention》[arXiv:2507.06457](https://arxiv.org/abs/2507.06457)（级别 A）**

- 训练并开源 **72 个模型**：36 个 @ **340M 参数 / 20B token**，36 个 @ 1.3B / 100B token；
  覆盖 **6 种线性注意力** × **5 种混合比例**（论文自述，见其 Abstract）。
- 结论（Abstract 原文）：「language modeling remains stable across linear-to-full attention ratios,
  **recall significantly improves with increased full attention layers, particularly below a 3:1 ratio**」；
  并明确推荐 **HGRN-2 或 GatedDeltaNet + linear:full 比例 3:1~6:1** 来「以低成本达到 Transformer 级 recall」。
- 另有一条对我们尤其重要的结论：**「standalone 更强的线性模型不必然是更好的混合体」**——
  即「把整个骨架换成某个更先进的门控线性注意力」这个直觉，在受控数据上**不成立**。
- 340M 段的下游均值（常识类，我实际抓到的表）：DeltaNet 6:1 **0.441**、GatedDeltaNet（纯）**0.442**、
  GLA 6:1 **0.441**、HGRN 6:1 **0.448**。
  解读：**四种跨代机制的差异只有 0.007（≈1.6%）**——在 340M/20B 这个预算下，
  「选哪个线性注意力」对 LM/下游几乎无影响，**差异集中体现在 recall 上**。
  （RetNet 与 HGRN-2 两行在我抓取时被 HTML 截断，未取到具体数字，不编。）

### 3.2 召回/复制/状态跟踪：线性家族的共同短板（多来源一致）

| 结论 | 具体数字 | 出处 | 级别 |
| --- | --- | --- | --- |
| SoTA gated-conv 在 Pile 上仍输 attention | 最多 **2.1 ppl**；**82% 的差距由 associative recall 解释** | **Zoology**, [arXiv:2312.04927](https://arxiv.org/abs/2312.04927) | **A**（17 个模型受控预训练） |
| 参数效率差距极端 | **70M 的 attention 模型在 associative recall 上超过 1.4B 的 gated-conv 模型** | 同上 | A |
| 混合可以补上 | 「input-dependent sparse attention 的混合体补掉 **97.4%** 的差距」 | 同上 | A |
| 复制任务上固定状态模型有根本差距 | 2 层 Transformer 可复制指数长串，GSSM 受固定潜状态限制；实测 Transformer 大幅胜出 | **Repeat After Me**, [arXiv:2402.01032](https://arxiv.org/abs/2402.01032) | **A**（含预训练 LLM 评测） |
| SSM 的状态跟踪是「幻觉」 | SSM 表达力被限制在 **TC⁰**，**无法**解 permutation composition；论文明确列出「按棋谱记棋、求值代码、长叙事中跟踪实体」 | **The Illusion of State in SSMs**（ICML 2024）, [arXiv:2404.08819](https://arxiv.org/abs/2404.08819) | **A** |
| 8B 尺度上纯 SSM 的短板仍在 | 纯 SSM 在需要强复制/ICL 的任务上落后（**5-shot MMLU、Phonebook**）与**长上下文推理**；而 43% Mamba-2 + 7% attention + 50% MLP 的混合在 **12 项任务上全部超过 8B Transformer，平均 +2.65 分**，并预测生成最多快 8× | **An Empirical Study of Mamba-based Language Models**, [arXiv:2406.07887](https://arxiv.org/abs/2406.07887) | **B**（NVIDIA 自研自测，但受控同数据） |

> 这四篇互相独立、方法不同，指向同一件事：**定长状态混不进「精确检索」这件事**。
> 对 RP 的直接含义是「记住设定里的名字/细节」，对 CoT 的直接含义是「多步中间量不能精确复读」。

### 3.3 第三代（delta rule）确实是唯一有稳定增益的一代

- **DeltaNet**（[arXiv:2406.06484](https://arxiv.org/abs/2406.06484)，级别 B，代码开源）：
  1.3B / 100B token，**ppl 与 zero-shot 下游均超过 Mamba 与 GLA**；
  两种混合（每两层插一层 sliding-window attention；**只加 2 层全局 attention**）**超过强 Transformer 基线**。
  → 「加 2 层 attention」这个最小改动就有实测收益，这是本报告推荐 A 的核心依据。
- **Gated DeltaNet**（ICLR 2025，[arXiv:2412.06464](https://arxiv.org/abs/2412.06464)，级别 B）：
  门控 + delta 规则互补（门控负责快速擦除、delta 负责定点改写），自报在语言建模、常识推理、
  上下文检索、长度外推、长上下文上一致超过 Mamba2 与 DeltaNet；与 SWA / Mamba2 混合可同时改善训练效率。
- **Kimi Linear / KDA**（[arXiv:2510.26692](https://arxiv.org/abs/2510.26692)，级别 B，**48B 总参数 / 3B 激活**）：
  「首次在全注意力持平比较下超过 full attention」，KV cache −75%、1M 上下文解码最高 6×。
  **但**：这是 3B 激活以上的工业级自报，对本项目只能作为「方向可信」的证据，**不能外推到 272M**。

### 4.3 【估算】换架构对 8GB 墙意味着什么：结构上帮不上忙

按 `checkpoints/retnet_272m_rp/config.json`（d=1024, H=16, kd=64, vhd=128, value_dim=2048, ffn=2048, L=2048）
做前向 FLOP/token 分解（**这是算术估算，不是实测**）：

| 部件 | MFLOP/token/层 | 占比 |
| --- | --- | --- |
| q/k 投影（2×d²） | 4.19 | 15.8% |
| v/g 投影（2×d×vd） | 8.39 | 31.6% |
| out_proj（2×vd×d） | 4.19 | 15.8% |
| FFN（2×2×d×ffn） | 8.39 | 31.6% |
| **retention 混合（chunk 128）** | **~1.31** | **~4.9%** |
| 单层合计 | ~26.5 | 100% |
| ×20 层 + lm_head（2×d×V） | **≈571 MFLOP/token** | — |

这和 `docs/11b` §3.5 实测的 **562.6 MFLOP/token** 同量级，验证了分解口径。

推论：

1. **retention 只占 4.9%**。把它换成别的线性机制，前向 FLOPs 变化在噪声量级；
   **8GB 墙来自「fp32 权重+梯度+优化器 ≈2.7 GiB + 激活」**（`docs/15` §3），
   而激活由 `[B,L,d]` 与 FFN 决定，与 mixer 是哪一族基本无关。**换架构不会解开 8GB 墙。**
2. 换成 **full softmax attention** 每层/token = `2L(d+vd)`：L=2048 时 **12.58 MFLOP**；
   即 20 层全换相当于 796 MFLOP/token（**+39%**），而**只换 4–5 层是 +8~10%**；
   在 L=512 时只换 5 层的增量 ≈0（attention 只要 3.15 MFLOP/层）。
   → **在当前窗口（512/2048）下，混合的算力代价小；真正变贵的是把窗口推到 8K+**
   （L=8192 时单层 attention 50.3 MFLOP ≈ 一整层的两倍）。
3. **推理 state 会变大**：当前 RetNet state = 20 层 × H×kd×vhd = 16×64×128 = 131,072 元素/层，
   共约 **5.2 MiB（bf16）**，与长度无关【估算，`docs/01` 的 2.4MB 是 12 头配置】；
   若插 5 层 attention，每 token 新增 `5 × 2 × kd × H × 2B = 20 KiB`，
   **8K CoT 输出 ≈ +164 MiB**，且不再 O(1)。这正是「长 CoT」与「混合化」之间的真实取舍点。
4. **最大风险不是数学是 kernel**：项目自己的 2.96× 提速完全来自 kernel 工程量（批量 chunkwise + 关检查点 + 8-bit Adam），
   而参考逐 chunk 循环比最优解慢 **3.03×**（2,176 → 714 ms）。
   **一个没有为 8GB 消费级卡调过的 Mamba-2 / DeltaNet 官方内核，很可能先让训练慢 2–3 倍，再谈质量。**

## 5. 长 CoT 友好度专章（本项目最缺的东西）

### 5.1 先说本项目现状（来自仓库，不是推测）

- 272M 基准 **0.1049**，七个类别零分；填空 0.07–0.20，数学全 0（`docs/03`/`docs/13`，`docs/04` §4）。
- v10 的 26.5% `<think>` 泄漏已定位为**数据把答案切掉了**，不是「模型没学会推理」（`docs/04` §4 末尾）。
- 门槛判断：有效 CoT 约 **0.5–1B**，可靠推理 7B 起（`docs/04` §4）。
- 小模型蒸馏长 CoT 的已知失败：强推理者的 CoT 常 >2,000 token，小模型容量装不下
  （*Small Models Struggle to Learn from Strong Reasoners*, ICML 2025, [arXiv:2502.12143](https://arxiv.org/abs/2502.12143)）。

### 5.2 反对「换成 SSM/纯线性」的证据

1. **表达力层面（最硬的一条）**：SSM 被限制在 TC⁰，**不能**解 permutation composition；
   论文直接把「按棋谱记棋、求值代码、长叙事中跟踪实体」列为做不到
   （[2404.08819](https://arxiv.org/abs/2404.08819)）。这三件事恰好是长 CoT 的本质动作。
2. **任务层面**：复制（[2402.01032](https://arxiv.org/abs/2402.01032)）、associative recall
   （[2312.04927](https://arxiv.org/abs/2312.04927)）、8B 的 5-shot MMLU / Phonebook / 长上下文推理
   （[2406.07887](https://arxiv.org/abs/2406.07887)）——四篇独立工作都指向纯 SSM 更差。
3. **理论层面对「混合」的支持（2026 新结果）**：在 parity-conditioned retrieval 任务上，
   **Gated DeltaNet + Gated Attention 的混合用 O(1) 步 CoT 就能解**，
   而**纯 Gated DeltaNet 没有同类解**，纯 Gated Attention 至少要多项式长的 scratchpad
   （*Provably Shorter Scratchpads in Hybrid DeltaNet-Attention Decoders*，
   [arXiv:2605.16640](https://arxiv.org/abs/2605.16640)，preprint / 审稿中）。
   → 直译成我们的语言：**要长 CoT，就要 attention 层，而且不能全是 linear 层。**

### 5.3 支持「线性/无 attention 也能推理」的证据（但有前提）

| 工作 | 做法 | 结果 | 对我们的可迁移性 |
| --- | --- | --- | --- |
| **M1**（[2504.10449](https://arxiv.org/abs/2504.10449)） | **混合** Mamba（28 层里 6 层 attention），从 Llama3.2-3B-Instruct **蒸馏**，10B 推理 token SFT（seq 24576）+ GRPO 50 步 | AIME25 23.5 / AIME24 28.9 / MATH500 82.1 / OlympiadBench 47.3，与 R1-Distill-Qwen-1.5B 持平；同尺寸比 vLLM Transformer **>3×** | **不可直接迁移**：3B、需要教师模型、需要 24K 窗口与 RL 管线。但它证明的是「**混合 + 蒸馏 + 长窗口**」，不是「纯 SSM」 |
| **PromptCoT-Mamba**（[2505.22425](https://arxiv.org/abs/2505.22425)） | **纯** Mamba-2 SSD（无 attention）7B + 两阶段课程微调（PromptCoT 合成数据） | 自报超过同规模 Transformer 与混合模型，并在 AIME24 上超 Gemma3-27B 2.6% | 7B 级、preprint、自报；**<1B 无对应结果** |

**综合判断（对本项目 272M）**：
长 CoT 与「选哪一族线性注意力」关系不大；与 **(a) 有没有 attention 层、(b) 窗口长度、
(c) 推理数据、(d) 参数量** 关系很大。把 272M RetNet 换成同尺寸纯 Mamba-2，**理论上限被判过死刑**
（§5.2 第 1 条），实测上也没有 <1B 的正向证据。**这是「不值得换」里最硬的一条理由。**

## 6. 逐个候选的可移植性与工作量

参考实现统一指向 **flash-linear-attention（fla）**：我核验了它的 `fla/layers/` 目录清单，
里面**同时存在** `multiscale_retention.py`（RetNet 自己）、`gla.py`、`simple_gla.py`、`gated_deltanet.py`、
`delta_net.py`、`gdn2.py`、`hgrn.py`、`hgrn2.py`、`rwkv6.py`、`rwkv7.py`、`kda.py`、`mamba.py`、
`mamba2.py`、`mamba3.py`、`attn.py`、`mla.py`、`yoco.py`、`nsa.py` 等
（来源：`https://api.github.com/repos/fla-org/flash-linear-attention/contents/fla/layers`）。
其 `pyproject.toml` 显示：基础依赖只有 `transformers>=4.45` + `einops`，**torch/triton 走 extras**
（`cuda = ["torch>=2.7.0","triton>=3.3"]`），`conv1d = ["causal-conv1d>=1.4.0"]` 是可选依赖，
`requires-python >=3.10`。
→ 结论：**fla 是唯一现实的「不自己写 kernel」路线**（Triton 版，理论上有 Windows wheel 可用），
但**本机是否真能跑通我没有验证**（按要求未跑 GPU 任务），且 C8（自研原则）需要项目自己权衡。

| 候选 | 能否接 C1/C2（数据+损失） | 三模式（C3） | 能否继承现有权重 | 与生长线（C5） | 估工作量 |
| --- | --- | --- | --- | --- | --- |
| **A. 混合 4–5 层 full/SWA attention** | ✅ 完全不动 | ⚠️ 需要**第二类 state**（这几层的 KV cache），`generate()`/`generate` 预填要分派 | ⚠️ 只能 warm-start（把 MSR 的 q/k/v/o 搬过去），loss 会跳 | ✅ 正交 | **200–400 行** + state 管理 + 测试 / 3–5 天 |
| **B. GLA per-channel 门控** | ✅ | ✅（chunked/recurrent 都有现成形式） | ✅ **函数保持**：log-decay 初值 = `log γ`、门控投影零初始化 ⇒ 初始化处恒等于现 MSR | ✅ 正交 | **300–600 行**（衰减表 `[H]`→`[H,C,kd]` + 新投影 + 三条路径等价性）/ 3–7 天 |
| **C. Delta/Gated DeltaNet 写入门** | ✅ | ✅ | ❌ 非函数保持（delta 更新 `S(I−βkkᵀ)+βvkᵀ` 与当前纯外积写入不等价） | ✅ | **400–800 行**（chunkwise 要重写）+ 重训 |
| **D. 换 Mamba-2 骨架** | ✅ | ✅（SSD 是 chunked 形式，递推形式存在） | ❌ 完全不可迁移（需要 conv1d、dt/B/C 投影，且无 xPos） | ✅ | **1–2 周** + **从零重训** |
| **E. 换 GLA 骨架** | ✅ | ✅ | ⚠️ 同 B 的初始化技巧可以做到「近似保持」 | ✅ | 1–2 周 + 重训 |
| **F. RWKV-6/7** | ✅ | ✅ | ❌ | ✅ | 1–2 周 + 重训（fla 有实现） |
| **G. xLSTM** | ✅ | ⚠️ sLSTM 是**不可并行**的递归，得写定制 kernel | ❌ | ? | **fla 里没有**；自研 kernel，最大 |
| **H. TTT / Titans / MesaNet** | ✅ | 研究阶段 | ❌ | ? | 无 <1B 实测，不建议投入 |

> **重训成本的硬数字**：按 `docs/15` 实测的 11,496 tok/s（272M、最优配置、理想连续运行）【估算】：
> 1B token ≈ **24 小时**；10B ≈ **10.1 天**；20B（340M 研究的预算量级）≈ **20.2 天**；100B ≈ **101 天**。
> 而 §3.1 说明在 340M/20B 这个预算下，**四种线性机制的 LM/下游差异只有 1.6%**——
> 也就是说这 20 天买不到 ppl，买到的是「recall 这条我们本来就测不准的轴」。

## 8. 建议动作（按性价比，全部是「加法」）

1. **先补护栏，再谈任何架构**：C4 那条「同一 state dict 装进两份实现得到 0 差异」的免费回归线现在**没人用**
   （`docs/11b` §3.9），而生产尺度 parallel↔chunkwise 差 6.77–8.39。**换任何 kernel/层之前先把它变成测试**，
   否则换了之后没有「错在哪」的判据。
2. **A（混合化）**：20 层里挑 4–5 层换 full attention（或 SWA），保持 3:1–6:1。
   预期 +8~10% 前向算力（L=2048）/ ≈0（L=512），换来 recall 与长 CoT scratchpad 的理论改善，
   而且**可以从现有权重 warm-start**。这是唯一一条「代价可控、证据方向一致」的架构改动。
3. **B（GLA per-channel 门控）**：函数保持的升级，能在不跳 loss 的前提下把「固定衰减」升级成
   「数据相关门控」——正是 340M 研究点名的有效设计轴。与 A 不冲突。
4. **C（delta 写入门）**：排在 A/B 之后；它针对 RP 记忆，但不是函数保持，且 chunkwise 要重写。
5. **把省下的预算投到「生长 + 数据」**：`docs/04` 已判定 272M 的结构化/数学是**尺度限制**；
   项目自己的比较优势是 `GrowthLayerNorm`（Δ7.25e-4）与已跑通的生长线。
   **在 272M 上换骨架，是用「我们唯一领先的能力」去换「一个在 <1B 没有实测优势的新骨架」。**
6. **不要**在没有 A/B 对照的情况下并行开两条骨架：8GB 单卡 + 无 `.git` + 一次重训 10–20 天的组合，
   失败一次就吃掉整个季度。
