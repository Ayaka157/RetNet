## 1. 目标

依据论文 [Retentive Network（arXiv:2307.08621v4）](./paper/2307.08621v4.pdf)
从零手写 RetNet（**不使用任何现成 Transformer/RetNet 模块**），在消费级显卡上训练一个
**中英角色扮演对话模型**。代码 / 数学 / 推理能力是「锦上添花」的加分项，主线是 RP。

## 2. 模型线

项目走过三条规模线，后两条是**生长**出来的，不是从头重训：

| 线 | 参数 | 怎么来的 | 时间 |
| --- | --- | --- | --- |
| **100M** | 100.37M（d768 / L12 / H12） | 从零训练 | 2026-08-19 ~ 08-23 |
| **143M** | 142.87M（d768 / **L18** / H12） | 深度生长 12→18 层 | 08-23 ~ 08-24 |
| **272M**（主线） | **272,304,448**（d1024 / L20 / H16 / value_dim 2048） | 宽度 + 深度联合生长 | 08-24 起 |

生长不是重新初始化：143M 逐层复制并零残差插入新层；272M 在加宽时用
`GrowthLayerNorm`（LN 只对旧 D 维生效，新通道走 γ=0 零侧分支）避免 pre-LN 的归一化统计污染，
实测函数保真 **Δ7.25e-4**。819M token 的预训练知识因此被完整继承。
原理与实测见 [`08_chunkwise_growth_research.md`](./08_chunkwise_growth_research.md)。

## 3. 架构要点（手写实现）

位置：`retnet/model.py`（手写）与 `retnet_hf/modeling_retnet.py`（HF 封装，143M/272M 线在用）。

| 机制 | 实现 |
| --- | --- |
| Retention（式 5–8） | `Q=(XW_Q)⊙Θ`、`K=(XW_K)⊙Θ̄`、`D_nm=γ^(n-m)`、`Retention=(QKᵀ⊙D)V` |
| 多尺度衰减 | `γ = 1 - 2^(-5-h)`，每头不同衰减率 |
| GLA 可学习门控 | `use_gla=true`：`γ` 是 `nn.Parameter`。**必须 fp32**——bf16 在 1.0 附近分辨率只有 2⁻⁸，会把 16 个头里的 12 个衰减塌缩成 1.0 |
| 输出门控 | `MSR(X) = (swish(XW_G) ⊙ GroupNorm_h(heads)) W_O`，每头独立 Sub-LN |
| xPos 相对位置 | 论文的复数 `e^{inθ}` 用等价的实数二维旋转；位置/频率全程 fp32 |
| 三种范式 | `parallel`（训练历史）/ `recurrent`（O(1) 推理）/ `chunkwise`（当前训练主线），共享同一组权重 |
| 权重共享 | 输出层与词嵌入 tied；参数量 `P ≈ 12·L·d² + V·d` |

**推理状态 O(1)**：每层 `key_dim × value_head_dim`，272M 全天候约 2.4MB，与上下文长度无关。
对比同规模 Transformer 的 KV cache：512 上下文约 19MB、4096 上下文约 151MB。

> ⚠️ **三种范式在生产尺度上不数值等价。** `tests/test_model.py` 的 `1e-4` 断言只在
> d_model=64 / L=16 成立；272M fp32 实测 parallel↔chunkwise `max|diff|` 到 **6.77**。
> 训练走 chunkwise，`generate()` 预填 prompt 走 parallel——这个不一致没有回归护栏。

## 5. 训练历程

18 个阶段，完整表格（每段的日志出处、中断原因、终值）在
[`12_训练状态盘点.md`](./12_训练状态盘点.md) §2。这里只列关键转折：

| 阶段 | 结果 | 意义 |
| --- | --- | --- |
| `retnet_23m` / `retnet_97m_wikitext103` | val ppl 75.30 / 50.39 | 验证三范式一致性与英文底座 |
| `retnet_100m_pretrain` | 全局最优 val ppl **36.17 @98k**，段末端退化到 38.65 | ⚠️ 后 10 万步验证集净退化（过拟合），最优不在终点 |
| `retnet_100m_chat_sft` | ppl 13.96 但**答非所问** | 暴露三个管线 bug，见 [`02`](./02_训练管线.md) §2 |
| `retnet_100m_chat_v3` | 回复 ppl 91.72 | 对齐 + 掩码修好，闲聊自然 |
| `retnet_100m_rp_v2` | 回复 ppl **8.25** | 100M 线最优 |
| `retnet_143m_rp` | eval_loss **2.6534** | 生长后首次超越 100M |
| `retnet_272m_rp` | eval_loss **2.9946**，1.498 steps/s，3h42m | 272M 首次跑通，**当前基准最优** |
| `retnet_272m_v10` | 65k 步跑满，eval_loss 2.3031，但 **26.5% think 泄漏** | 综合能力路线：能力略优于 rp（p=0.084，不显著），格式有缺陷 |
| `retnet_272m_v13` | 训练中（2026-10-09 夜） | 修正 R1 截断后重训 |

> **跨数据集 eval_loss 不可比。** v10 的 2.3031 与 rp 的 2.9946 用的是不同验证集
> （v10 val 2,866 行 / rp val 1,561 行）。可比的是基准分：**v10 0.3848 vs rp 0.3587**
> （143 项 × 8 种子，配对 p=0.084，方向是 v10 略优但不显著）。
