## 4. 已知的权限问题（未解决）

`Kaggle/_audit/checks/` 下有三个 `tmp*` 目录（`tmpa3758029`、`tmpadjufmpf`、`tmpr957s6fh`）
**连 ACL 都读不到，也删不掉**。

- 体检结论：该目录**属主是 `Administrators` 组而非当前用户**，普通（未提权）会话缺少「修改权限」资格
- **不是 DSH 沙箱限制**——本会话已是完全访问；这是 Windows 侧的属主问题
- ACL 诊断脚本拒绝修复并留了报告：`logs/acl-repair/`（`FIXED=0 GRANTED=0 REFUSED=1 RESTORED=0`，无改动、无需回滚）
- 影响：`Kaggle/_audit/checks` 下递归列目录会报错，其余无影响
- 修法（需**管理员** PowerShell，我无法提权）：

```powershell
takeown /f "E:\Workspaces\RetNet\Kaggle\_audit\checks" /r /d y
icacls "E:\Workspaces\RetNet\Kaggle\_audit\checks" /grant "${env:USERNAME}:(OI)(CI)F" /t
Remove-Item -Recurse -Force "E:\Workspaces\RetNet\Kaggle\_audit\checks\tmpa3758029","E:\Workspaces\RetNet\Kaggle\_audit\checks\tmpadjufmpf","E:\Workspaces\RetNet\Kaggle\_audit\checks\tmpr957s6fh"
```

## 6. 运维速查

```powershell
# 查看训练
nvidia-smi --query-gpu=temperature.gpu,utilization.gpu,memory.used --format=csv
ssh Ayaka@192.168.1.100 'powershell -NoProfile -Command "Get-Content C:\Users\Ayaka\RetNet\logs\v13_272m_2k.log -Tail 5"'

# 中断/续训
python run_task.py --config tasks\v13_272m_2k.json --resume

# 睡眠防护
powercfg /change standby-timeout-ac 0
powercfg /change monitor-timeout-ac 10
```

| 突发 | 处理 |
| --- | --- |
| CUDA OOM | `--batch_size` 减半；seq 2048 batch 4 已占 7.58 GB，只剩约 600 MB 余量 |
| loss NaN / Inf | 从最后 checkpoint 恢复，LR 砍半，`--max_grad_norm 1.0` 不动 |
| 生成出现 `<think>` 不收尾 | **不是采样问题，是数据缺陷**——两级截断切掉了 `</think>` 与答案，见 [`02`](./02_训练管线.md) §3 |
| 远程训练没起来 | 查进程 → 查日志字节数 → 查 GPU 占用。若用 `Start-Process` 起的必然失败，改 `schtasks` |
| 断电 | `run_task.py` 配了 `auto_restart_max` 自动 resume |
