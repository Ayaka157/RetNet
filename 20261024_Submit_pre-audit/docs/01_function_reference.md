    def get_decay_parameter_names(self, model) -> list[str]:
        """哪些参数要施加 weight decay。默认规则只排除 bias 与 LayerNorm.weight，
        而 `msr.gamma` 是**裸 nn.Parameter**，两头都不沾，于是被 wd=0.1 一路拉小。

        实测代价（2026-10-18，subagent 从 safetensors 里读出来的）：
        gamma 从初值 1-2^(-5-h) 降到 0.667(ep1) → 0.601(ep2) → 0.543(ep3)，
        每 epoch 稳定 ×0.90 —— 这正是 AdamW 解耦权重衰减的固定衰减率，不是学出来的；
        10 个头的 gamma 在 20 层里**逐位相同**（0.542977±1e-6）就是铁证。
        后果：半衰期从 22–1400 token 掉到约 1 token，**有效上下文只剩约 500 token**，
        2048 窗口后 3/4 用不上。

        修法：所有 **1 维参数**（各种 norm 的 scale、门控、衰减）都不做衰减。
        用 ``--no_decay_1d`` 开启，默认关闭以保持与历史 run 一致。
        """
        names = super().get_decay_parameter_names(model)
        if not getattr(self, "_no_decay_1d", False):
            return names
        one_d = {n for n, p in model.named_parameters() if p.ndim <= 1}
        kept = [n for n in names if n not in one_d]
        dropped = len(names) - len(kept)
        if dropped and not getattr(self, "_no_decay_logged", False):
            self._no_decay_logged = True
            print(f"[opt] 1 维参数移出 weight decay：{dropped} 个"
                  f"（含 gamma）", flush=True)
        return kept
```

Decides which parameters receive weight decay. The parent class's default rule excludes only bias and LayerNorm.weight, whereas msr.gamma is a bare nn.Parameter that matches neither exclusion, so it was steadily shrunk multiplicatively by wd=0.1. When _no_decay_1d is enabled, this method removes every one-dimensional parameter (the norm scale, the gates, and gamma) from the decay set and prints the number removed on the first call. It is the fix point for E06: the default has been changed to enabled, and whether gamma is still in the decay set is now a hard assertion checked before training starts.

### `CompileSafeTrainer.save_model` (L76–L90)

**00 links**: none

```python
    def save_model(self, output_dir=None, _internal_call=False):
        inner = getattr(self.model, "_orig_mod", None)
        if inner is None:
            return super().save_model(output_dir, _internal_call)
        wrapped = self.model
        prev_wrapped = getattr(self, "model_wrapped", None)
        self.model = inner
        if getattr(prev_wrapped, "_orig_mod", None) is inner:
            self.model_wrapped = inner
        try:
            return super().save_model(output_dir, _internal_call)
        finally:
            self.model = wrapped
            if prev_wrapped is not None:
                self.model_wrapped = prev_wrapped
```

Works around the OptimizedModule prefix problem introduced by torch.compile. When the model is wrapped in an OptimizedModule, every key in the state_dict carries the _orig_mod. prefix; loading such a checkpoint with from_pretrained raises no error, it simply discards all the keys as unexpected, so the result is a randomly initialized model. This method temporarily swaps self.model back to the inner model before saving and swaps it back afterwards, so the key names written to disk are clean and both the resume and the export path end up correct.

def verify_export(path) -> bool:
    """导出后自检：safetensors 的键里不能有 ``_orig_mod.``，且必须能真的加载。

    这道检查很便宜，但它是唯一能在"训练日志一切正常、模型文件却不可用"
    这种情形下把问题挡在前面的东西。
    """
    import json as _json
    import struct
    wf = Path(path) / "model.safetensors"
    if not wf.exists():
        print(f"[verify] !! 找不到 {wf}")
        return False
    try:
        with open(wf, "rb") as fh:
            n = struct.unpack("<Q", fh.read(8))[0]
            hdr = _json.loads(fh.read(n).decode("utf-8"))
        keys = [k for k in hdr if k != "__metadata__"]
        bad = [k for k in keys if k.startswith("_orig_mod.")]
        if bad:
            print(f"[verify] ❌ 导出里有 {len(bad)}/{len(keys)} 个键带 _orig_mod. 前缀 —— "
                  f"这个检查点用 from_pretrained 加载会**静默变成随机模型**。"
                  f"跑 scripts/strip_compile_prefix.py 修，或检查 CompileSafeTrainer 是否生效。")
            return False
        print(f"[verify] ✅ 导出键名干净（{len(keys)} 个），可直接 from_pretrained")
        return True
    except Exception as exc:                                   # noqa: BLE001
        print(f"[verify] 跳过（{type(exc).__name__}: {exc}）")
        return True
```

Post-export self-check: reads the safetensors header JSON, checks that no key name carries the _orig_mod. prefix, and confirms that the file exists. It validates only the shape of the key names, not the values, so it cannot detect all-zero parameters or dead dimensions; that is exactly the point E08 makes: passing this check does not mean the model can train or can be used, only that loading will not fail silently. The newly added live-parameter statistics and gradient-coverage check are what fill this gap.

```python
def live_param_ratio(model):
    """返回 (非零参数数, 总参数数, 比例)。参数量本身不说明任何问题（E08）。"""
    total = sum(p.numel() for p in model.parameters())
    live = sum(int((p != 0).sum()) for p in model.parameters())
    return live, total, (live / max(1, total))
```

Computes the fraction of nonzero parameters in the model (E08). The old code printed only the sum of numel, so 504,179,896 still displayed as 504M even if 67% of it was exactly 0. This function separates 'nominal parameters' from 'learnable parameters' so that _preflight can decide whether to refuse to start training; it is also tested directly by test_live_params.py. Note that the GroupNorm bias is initialized to 0, so even a fresh model's ratio is not 100%; the absolute value is meaningless, and the magnitude worth watching is whether it has dropped by a large margin.

```python
def read_live_baseline(*dirs) -> float | None:
    """读取某个历史 run 记录下来的活参数比例；没有记录就返回 None。

    优先读 ``ratio_min``（历史最低），而不是最近一次的 ``ratio``：否则每轮
    悄悄掉 1%（低于 2% 容差）都会被接受，然后把基线重设到更低的位置，
    连续几十轮就等于没有守卫。
    """
    import json
    for d in dirs:
        if d is None:
            continue
        p = Path(d) / LIVE_PARAMS_FILE
        if not p.is_file():
            continue
        try:
            data = json.loads(p.read_text(encoding="utf-8"))
            ratio = float(data.get("ratio_min", data["ratio"]))
        except Exception:                                   # noqa: BLE001
            continue
        if 0.0 < ratio <= 1.0:
            return ratio
    return None
```

Reads the live-parameter fraction that a historical run wrote into live_params.json (E08). The directories passed in are searched in order and the first value that parses and falls in (0,1] wins; ratio_min (the historical minimum) is preferred, so that slow erosion which quietly loses 1% per round and is then erased by a reset baseline does not slip past the guard. A missing or corrupt file returns None. Its purpose is to let training continue from a pruned checkpoint with 33% live parameters without manually toggling a flag every time: as long as the previous successful training start recorded a baseline and the ratio has not degraded noticeably, it passes automatically.

### `write_live_baseline` (L229–L246)

```python
def write_live_baseline(d, live: int, total: int, ratio: float,
                        previous: float | None = None) -> Path:
    """记录本次开训时的活参数比例，供下一次续训判断“有没有变得更死”。

    ``ratio_min`` 保留历史最低值（含本次），这样缓慢侵蚀不会被“每次都重设
    基线”抹掉；``ratio`` 仍记录本次实测值，便于看趋势。
    """
    import json
    p = Path(d) / LIVE_PARAMS_FILE
    p.parent.mkdir(parents=True, exist_ok=True)
    prev_min = ratio if previous is None else min(float(previous), ratio)
    p.write_text(json.dumps({"live": int(live), "total": int(total),
                             "ratio": float(ratio),
                             "ratio_min": float(prev_min),
                             "written_at": __import__("time").strftime(
                                 "%Y-%m-%d %H:%M:%S")},
                            ensure_ascii=False, indent=2), encoding="utf-8")
    return p
```

Write the live parameter count at the start of this run, the total count, this run's ratio, the historical minimum ratio (ratio_min) and the timestamp into output_dir/live_params.json (E08). It is called only on rank 0 and only after training has finished successfully; a write failure merely warns and does not invalidate a training run that has already completed. The next resumed run reads it from model_dir or output_dir and can then tell a "known pruning state" from "this round killed the parameters again" — in the latter case the ratio falls below the baseline and the guard still rejects it.

                      f"一致（容差 {tol * 100:.0f}%）：这是已记录的剪枝/生长状态")

### `GradCoverageCallback.__init__` (L308–L322)

```python
    def __init__(self, model, tol: float = DEFAULT_DEAD_GRAD_TOL,
                 check_step: int = 1):
        self.model = model
        self.tol = float(tol)
        self.check_step = int(check_step)

        self._numel: dict[str, int] = {}

Registers a backward hook on every parameter with requires_grad and records the element count of each parameter (E07). A hook must not be registered on parameters with requires_grad=False, because PyTorch raises a RuntimeError immediately; such parameters never have gradients anyway, so keeping them in _numel is enough for them to be classified as dead parameters. The hooks must be registered at construction time and cannot wait until on_step_end: HF calls zero_grad after optimizer.step(), so by the time the callback fires p.grad is already None.

### `GradCoverageCallback._make_hook` (L324–L332)

**00 links**: E07

```python
    def _make_hook(self, name: str):
        def _hook(grad):
            if grad is None:
                return grad
            v = float(grad.detach().abs().max()) if grad.numel() else 0.0
            prev = self._seen.get(name)
            self._seen[name] = v if prev is None else max(prev, v)
            return grad
        return _hook
```

Builds the hook for a single parameter: during backward it takes the maximum absolute value of that parameter's gradient and, after taking the max with the historical value, records the result in _seen. The hook returns the gradient unchanged and does not alter any value; max rather than the latest value is used in order to cover the multiple micro-batches of gradient accumulation (as long as one micro-batch receives a nonzero gradient, the parameter is not dead).

### `decay_group_1d_violations` (L378–L394)

**00 links**: E06

```python
def decay_group_1d_violations(model, optimizer) -> list[str]:
    """返回优化器里 ``weight_decay>0`` 的参数组中出现的 1 维参数名（E06）。

    这是比“训练中 gamma 有没有变小”更直接的判据：E06 的根因就是
    ``msr.gamma``（以及各种 norm scale）落进了带 weight decay 的组。
    直接查最终优化器分组，不依赖参数命名规则的重实现。
    """
    id2name = {id(p): n for n, p in model.named_parameters()}
    one_d = {id(p) for p in model.parameters() if p.ndim <= 1}
    bad: list[str] = []
    for gi, group in enumerate(getattr(optimizer, "param_groups", []) or []):
        if float(group.get("weight_decay", 0.0) or 0.0) <= 0.0:
            continue
        for p in group.get("params", []):
            if id(p) in one_d:
                bad.append(id2name.get(id(p), f"<unnamed in group {gi}>"))
    return bad
```

Inspects the optimizer parameter groups: it returns the names of all 1-D parameters that appear in a group with weight_decay>0 (E06). This is a more direct criterion than asking whether gamma shrank during training, because gamma legitimately changes as training proceeds, whereas 'a 1-D parameter must not appear in a decay group' is a structural hard constraint. Parameters are matched by id(), without relying on a re-implementation of the parameter naming rules.

```python
def _preflight(model, args, baseline: float | None = None) -> None:
    """开训前的硬检查：活参数比例 + gamma 分布。任一不过就拒绝开训。

    为什么需要它（docs/00 E08）：参数量是从 config 数出来的，
    504,179,896 哪怕 67% 是精确 0 也照样打印 504M。这里直接扫权重数值，
    把“名义参数”和“可学参数”分开。判定规则（含剪枝检查点的豁免）在
    ``check_live_ratio`` 里，是纯函数，便于测试边界。

    gamma 的检查对应 E06：衰减率被 weight decay 压小后，半衰期会从
    22~1400 token 掉到约 1 token，跨 chunk 的信息在数值上等于零。
    这里做下限检查（<=0 直接拒绝）并打印分布；gamma 是否仍在 weight decay
    集合里，由训练开始时的 ``DecayGuardCallback`` 直接查优化器参数组。
    **注意**：`use_gla=False` 时 gamma 是 buffer 而不是 Parameter，
    旧实现只遍历 `named_parameters()`，那种模型上这条检查是死的。
    """
    live, total, ratio = live_param_ratio(model)
    print(f"[preflight] live params {live:,}/{total:,} = {ratio * 100:.2f}%", flush=True)
    threshold = float(getattr(args, "min_live_ratio", DEFAULT_MIN_LIVE_RATIO))
    ok, why = check_live_ratio(ratio, threshold,
                               allow_dead=bool(getattr(args, "allow_dead_params", False)),
                               baseline=baseline)
    print(f"[preflight] 活参数判定：{why}", flush=True)
    if not ok:
        raise SystemExit("[preflight] " + why)

    # gamma 可能是 Parameter（use_gla=True）也可能是 buffer（use_gla=False），
    # 两头都收，否则后者这条检查静默失效。
    gammas = [t.detach().float().flatten()
              for n, t in list(model.named_parameters()) + list(model.named_buffers())
              if n.endswith("msr.gamma")]
    if gammas:
        g = torch.cat(gammas)
        print(f"[preflight] gamma n={g.numel()} min={g.min():.4f} "
              f"p50={g.median():.4f} max={g.max():.4f}", flush=True)
        if float(g.min()) <= 0.0:
            raise SystemExit("[preflight] gamma 里有 <=0 的值：log(0) 会让整层 NaN。")
    else:
        print("[preflight] ⚠️ 没找到任何 msr.gamma（参数或 buffer），gamma 检查跳过",
              flush=True)
```

Hard checks before training starts, called after the model is loaded and before the Trainer is constructed. It does two things: first, it scans the weights and computes the numeric statistic 'fraction of nonzero parameters', and exits via SystemExit if that is below 95%, because the parameter count is tallied from config and would print 504M even if 67% of it were exactly 0 (E08); second, it collects every msr.gamma and prints the distribution, rejecting outright if any value is <=0, so that log(0) cannot turn a whole layer into NaN (E06). It only checks what can be checked before training starts; whether gamma is decayed during training is the job of a separate step-ratio assertion.

        _sync_resume_state(Path(last), training_args)
        resume_arg = last
    else:
        resume_arg = False

### `ce_chunk_tokens` (L36–L43)

**00 links**: E22

```python
def ce_chunk_tokens(vocab_size: int, chunk_bytes: int = DEFAULT_CE_CHUNK_BYTES) -> int:
    """按字节预算反推每个 CE 分块能放多少 token（至少 1）。

    单独成函数是为了让测试能直接断言“生产形状下必须切出多块”，而不是只
    验证数值等价 —— 旧测试传 ``chunk_tokens=7``，即使参数被无视也会通过。
    """
    per_token = 4 * max(1, int(vocab_size))          # fp32 logits，每 token V 个 float
    return max(1, int(chunk_bytes) // per_token)
```

Derives from a byte budget how many tokens a cross-entropy chunk can hold: chunk_bytes // (4*V), at least 1 (E22). At V=20000 and a 64 MB budget that is 838 tokens/chunk, so the production shape B=16/L=2048 is sliced into 40 chunks. The old implementation fixed the chunk at 262144 tokens, independent of V and larger than the total number of production tokens, so there was only one chunk and the 2.6 GB fp32 copy stood there untouched. It is a separate function so that this arithmetic can be asserted directly.

Computes the key dimension of a single attention head, equal to d_model divided by num_heads. Rotates the two adjacent components (x0, x1) of the last dimension into (-x1, x0), the real-valued equivalent of the complex multiplication e^{i theta} * (a+bi). RetNet uses rotary position encoding to inject absolute position information into q and k, and the rotation angle is determined jointly by the position and the frequency table. This function performs only a shape transformation and introduces no learnable parameters, so it never shows up in the optimizer state.

```python
    def _project_and_rotate(self, x, offset):
        bsz, tgt_len, _ = x.shape
        q = self.q_proj(x).view(bsz, tgt_len, self.num_heads, self.key_dim).transpose(1, 2)

        k = theta_shift(k, sin, cos)

The four returned tensors go into the retention computation and the output gate respectively; the scaling is written onto k rather than onto the scores so that the chunkwise and the recurrent path share the same single scaling.

### `MultiScaleRetention._decay_mask` (L191–L202)

**00 links**: E16

```python
    def _decay_mask(self, length, device, dtype):
        idx = torch.arange(length, device=device)
        delta = idx[:, None] - idx[None, :]
        causal = delta >= 0
        exp = delta.masked_fill(~causal, 0)
        mask = self.gamma.to(device=device, dtype=torch.float32)[:, None, None] ** exp
        mask = mask.masked_fill(~causal, 0.0)
        # 2026-10-20: 删除了原来的 `mask / mask.sum(...).sqrt()`。
        # 那一步只存在于 parallel 路径，chunkwise/recurrent 都没有，导致
        # 训练（chunkwise）与生成 prefill（parallel）算的不是同一个函数。
        # 见 docs/00 E16。
        return mask.to(dtype=dtype)
```

Build the [H,L,L] decay mask: delta is the position difference, causal guarantees that only the past is visible, gamma raised to the power delta gives the exponential decay, and non-causal positions are explicitly set to 0. The current implementation no longer performs any row-wise normalization on the mask — on 2026-10-20 the former mask/sqrt(sum(mask)) was removed, because that step existed only on the parallel path and made training (chunkwise) and prefill (parallel) compute different functions (E16). The mask depends only on gamma and the position difference and itself contains no learnable parameters.

### `MultiScaleRetention._parallel_final_state` (L212–L220)

**00 links**: none

```python
    def _parallel_final_state(self, k, v, state):
        bsz, _, tgt_len, key_dim = k.shape
        idx = torch.arange(tgt_len, device=k.device)
        weights = self.gamma.to(device=k.device, dtype=torch.float32)[:, None] ** (tgt_len - 1 - idx)
        new_state = torch.einsum("bhtk,bhtv,ht->bhkv", k, v, weights.to(k.dtype))
        if state is not None:
            gamma_pow = self.gamma.to(device=k.device, dtype=k.dtype) ** tgt_len
            new_state = gamma_pow.view(1, -1, 1, 1) * state + new_state
        return new_state
```

Computes the recurrent state at the end of a full sequence in one shot: for each position it weights by gamma raised to the power (tgt_len-1-i) and then applies an einsum, producing [B,H,kd,vd]; if a historical state already exists, that state is decayed by gamma^tgt_len and added. It is called only when return_state is true, so that decoding can switch to a per-token loop after prefill. Note that it uses the full sequence length as the decay exponent, which is mathematically consistent with the per-chunk decay used by chunkwise.

### `MultiScaleRetention._recurrent_retention` (L222–L243)

**00 links**: E21

```python
    def _recurrent_retention(self, q, k, v, state):
        bsz, _, tgt_len, key_dim = q.shape
        value_head_dim = v.shape[-1]
        if state is None:
            state = torch.zeros(bsz, self.num_heads, key_dim, value_head_dim,
                                device=q.device, dtype=q.dtype)
        gamma = self.gamma.to(device=q.device, dtype=q.dtype)
        # docs/00 E21：解码时 tgt_len 恒为 1，走快路径，省掉 Python 循环与
        # list/stack 的物化。数学与下面的循环逐位相同。
        if tgt_len == 1:
            state = gamma.view(1, -1, 1, 1) * state + \
                k[:, :, 0, :].unsqueeze(-1) * v[:, :, 0, :].unsqueeze(-2)
            out = torch.sum(q[:, :, 0, :].unsqueeze(-1) * state, dim=-2).unsqueeze(2)
            return out, state
        outputs = []
        for t in range(tgt_len):
            state = gamma.view(1, -1, 1, 1) * state + \
                k[:, :, t, :].unsqueeze(-1) * v[:, :, t, :].unsqueeze(-2)
            out_t = torch.sum(q[:, :, t, :].unsqueeze(-1) * state, dim=-2)
            outputs.append(out_t)
        output = torch.stack(outputs, dim=2)
        return output, state
```

The token-by-token recurrent path: the state is decayed by gamma, the current token's k⊗v is added, and q is then dotted with the state. It is the implementation basis for O(1) inference and also the most intuitive of the three paths. E21 added a fast path for tgt_len==1: decoding has only a single step each time, so it is computed directly, saving the Python loop and the materialization of list/stack, and it is bitwise identical to the loop version; long sequences still take the loop, which is used only in rare scenarios.

see [01][04]

### `MultiScaleRetention._chunkwise_retention` (L245–L280)

**00 links**: E16

```python
    def _chunkwise_retention(self, q, k, v, state, chunk_size):
        """Equation (7): inner-chunk parallel + cross-chunk recurrent state."""
        if FAST_CHUNKWISE:
            from .retention_fast import chunkwise_batched
            return chunkwise_batched(q, k, v, self.gamma, state, chunk_size)
        bsz, _, tgt_len, key_dim = q.shape
        if tgt_len % chunk_size != 0:
            raise ValueError(f"chunkwise mode requires seq_len ({tgt_len}) to be a "
                             f"multiple of chunk_size ({chunk_size})")
        if state is None:
            state = torch.zeros(bsz, self.num_heads, key_dim, v.shape[-1],
                                device=q.device, dtype=q.dtype)
        gamma = self.gamma.to(device=q.device, dtype=q.dtype)
        outputs = []
        rel = torch.arange(chunk_size, device=q.device)
        delta = rel[:, None] - rel[None, :]
        causal = delta >= 0
        inner_mask = torch.where(causal, gamma[:, None, None] ** delta.masked_fill(~causal, 0),
                                 torch.zeros_like(delta, dtype=torch.float32))
        cross_decay = gamma[:, None] ** (rel + 1)[None, :]
        value_decay = gamma[:, None] ** (chunk_size - 1 - rel)[None, :]
        chunk_decay = gamma ** chunk_size

        for i in range(tgt_len // chunk_size):
            sl = slice(i * chunk_size, (i + 1) * chunk_size)
            qi, ki, vi = q[:, :, sl], k[:, :, sl], v[:, :, sl]
            inner_scores = torch.matmul(qi, ki.transpose(-1, -2)) * inner_mask
            inner = torch.matmul(inner_scores, vi)
            cross = torch.matmul(qi * cross_decay[None, :, :, None], state)
            outputs.append(inner + cross)
            weighted_v = vi * value_decay[None, :, :, None]
            state = chunk_decay.view(1, -1, 1, 1) * state + \
                torch.matmul(ki.transpose(-1, -2), weighted_v)

        output = torch.cat(outputs, dim=2)
        return output, state
```

The main training path: split the sequence into chunks, use the parallel decay mask inside each chunk, and pass the state recursively between chunks. The state update is S=gamma^C·S+k^T·(v·gamma^{C-1-j}), and the cross-chunk contribution is (q·gamma^{j+1})·S. It requires tgt_len to be divisible by chunk_size and otherwise raises an error immediately. Apart from E16, this path itself is correct, but it depends on the length of gamma: under the measured median, gamma^128 is roughly 1e-32, so cross-chunk information is effectively zeroed out.

see [01][04]

```python
    def forward(self, x, mode="parallel", state=None, offset=0, return_state=False,
                chunk_size=64):

        do_ckpt = self.gradient_checkpointing and self.training
        if do_ckpt and 0 <= self.checkpoint_layers <= self.layer_idx:
            do_ckpt = False          # 分层策略：只检查点前 checkpoint_layers 层
        if do_ckpt:
            return torch.utils.checkpoint.checkpoint(
                self._block_forward, x, mode, state, offset, return_state, chunk_size,
                use_reentrant=False)
        return self._block_forward(x, mode, state, offset, return_state, chunk_size)
```

Wraps a gradient checkpoint around _block_forward: it is enabled only in training mode and only when this layer's index is **less than** the checkpoint threshold (checkpoint_layers); at a layer index >= the threshold it is disabled. It uses the non-reentrant version, use_reentrant=False, to avoid conflicts with torch.compile graph capture. Checkpointing affects only GPU memory and recomputation and never the mathematics; when it is disabled, _block_forward is called directly.

```python
def _chunked_weighted_ce(logits, labels, wcodes=None, prompt_loss_weight=0.1,
                         chunk_tokens: int | None = None,
                         chunk_bytes: int = DEFAULT_CE_CHUNK_BYTES):
    """分块计算加权交叉熵，避免把整个 [B,L,V] 转成 fp32（docs/00 E22）。

    旧实现是 ``logits_f = logits.float()`` 之后一次性 reshape 求 CE。
    对本项目（B=16, L=2048, V=20000）那一步会物化 16×2048×20000×4 ≈ 2.6 GB
    的 fp32 副本，是显存峰值的主要来源；而 logits 本身还是 bf16，已经占 1.3 GB。

    分块大小**由字节预算反推**（``ce_chunk_tokens``），不是固定 token 数：
    每块只把 [chunk, V] 转 fp32，峰值约为 ``chunk_bytes`` 的量级。默认 64 MB
    在 V=20000 时是 838 token/块，于是生产形状 B=16/L=2048 会切出 40 块，
    而不是旧实现的一块 2.6 GB。显式传 ``chunk_tokens`` 仍可覆盖（测试用）。

    权重码语义与旧实现完全一致：pad=0 不计、reply/plain=1、prompt=prompt_loss_weight，
    最后除以权重和；没有 wcodes 时退化为普通均值。
    """
    V = logits.shape[-1]
    flat_logits = logits.reshape(-1, V)
    flat_labels = labels.reshape(-1)
    n = flat_logits.shape[0]
    if chunk_tokens is None:
        chunk_tokens = ce_chunk_tokens(V, chunk_bytes)
    chunk_tokens = max(1, int(chunk_tokens))

    w = None
    if wcodes is not None:
        w = torch.zeros_like(wcodes, dtype=torch.float32)
        w = torch.where(wcodes == 1, torch.ones_like(w), w)
        w = torch.where(wcodes == 2, torch.full_like(w, float(prompt_loss_weight)), w)
        w = torch.where(wcodes == 3, torch.ones_like(w), w)
        w = w.reshape(-1)

    total = torch.zeros((), device=flat_logits.device, dtype=torch.float32)
    denom = torch.zeros((), device=flat_logits.device, dtype=torch.float32)
    for s in range(0, n, chunk_tokens):
        e = min(s + chunk_tokens, n)
        ce = F.cross_entropy(flat_logits[s:e].float(), flat_labels[s:e], reduction="none")
        if w is None:
            total = total + ce.sum()
            denom = denom + float(e - s)
        else:
            total = total + (ce * w[s:e]).sum()
            denom = denom + w[s:e].sum()
    return total / denom.clamp_min(1.0)
```

Chunked weighted cross-entropy, replacing the previous code that called .float() on the entire logits tensor (E22). The old implementation, logits_f = logits.float(), would materialize roughly 2.6 GB of fp32 copy for B=16/L=2048/V=20000; this function instead derives the number of tokens per chunk from a **byte budget** (64 MB by default, which is 838 tokens/chunk at V=20000), converts only [chunk,V] to fp32 per chunk, and therefore slices the production shape B=16/L=2048 into 40 chunks instead of the single chunk of the old implementation. The weight-code semantics are exactly identical to the old implementation: pad=0 is excluded, reply/plain=1, prompt=prompt_loss_weight, and the result is finally divided by the sum of weights; when there is no wcodes it degenerates to a plain mean. Passing chunk_tokens explicitly overrides the budget (used by tests).

**00 links**: E22

```python
    def _forward_hidden(self, input_ids, mode="parallel", states=None, offset=0,
                        return_state=False, chunk_size=64, return_hidden=False,
                        need_state=None):
        """跑完所有 block，返回 logits（或 ``return_hidden`` 时的 final_norm 输出）。

        ``need_state`` 与 ``return_state`` 分开：融合交叉熵只想要 hidden，完全
        不需要每层的递归状态，但旧签名里 ``return_state=True`` 会让每个 block 都
        算一次 ``_parallel_final_state``（对 ``[B,H,L,kd,vd]`` 做 einsum）再把结果
        丢掉。显式传 ``need_state=False`` 就能跳掉这部分（E22/P2 性能项）。
        """
        if input_ids.ndim != 2:
            raise ValueError("input_ids must be [batch, seq]")
        x = self.embedding(input_ids) * self.embed_scale
        x = self.embed_dropout(x)
        if states is None:
            states = [None] * len(self.blocks)
        if len(states) != len(self.blocks):
            raise ValueError("states must contain one entry per block")
        # 递归模式必须返回状态（解码靠它推进）；其余路径由调用方决定。
        want_state = (return_state if need_state is None else bool(need_state)) \
            or mode == "recurrent"
        new_states: List[Optional[torch.Tensor]] = []
        for block, block_state in zip(self.blocks, states):
            if want_state:
                x, ns = block(x, mode=mode, state=block_state, offset=offset,
                              return_state=True, chunk_size=chunk_size)
                new_states.append(ns)
            else:
                x = block(x, mode=mode, state=block_state, offset=offset,
                          chunk_size=chunk_size)
                new_states.append(block_state)
        x = self.final_norm(x)
        if return_hidden:
            # 融合交叉熵需要的是 LM head 的**输入**（hidden），不是输出。
            # 这里提前返回可以完全不物化 [B,L,V]。
            if want_state:
                return x, new_states
            return x
        logits = self.lm_head(x)
        if want_state:
            return logits, new_states
        return logits
```

Model backbone: the embedding is multiplied by embed_scale and passed through dropout, then the blocks are called layer by layer, and finally final_norm is applied. When return_hidden is true it returns the hidden states early and hands them to the fused cross-entropy, avoiding materializing a [B,L,V] tensor; otherwise they go through lm_head to produce logits. states carries the per-layer state when doing recurrent/chunkwise inference, and its length must match the number of layers or an error is raised immediately.

```python
    def generate(self, input_ids: torch.Tensor, max_new_tokens: int = 32,
                 temperature: float = 1.0, top_k: Optional[int] = None,
                 top_p: Optional[float] = None, repetition_penalty: float = 1.0,
                 eos_id: Optional[int] = None, device: Optional[torch.device] = None,
                 penalize_prompt: bool = False, no_repeat_ngram_size: int = 0,
                 on_token=None) -> torch.Tensor:
        """Autoregressive generation (same algorithm/sampling as handwritten).

        ``on_token(token_id)`` is called for every accepted token, in order, as
        soon as it is sampled.  Returning a truthy value stops generation
        immediately (the token is still part of the returned sequence).  Used by
        the interactive play script to stream output and to cut a reply at the
        first ``用户：`` / ``助手：`` turn boundary.
        """
        device = device or next(self.parameters()).device
        ids = input_ids.to(device)
        states = [None] * len(self.blocks)
        if ids.shape[1] > 1:
            logits, states = self._forward_hidden(ids, mode="parallel", return_state=True)
            next_logits = logits[:, -1]
        else:
            next_logits, states = self._forward_hidden(ids, mode="recurrent", states=states,
                                                       offset=0, return_state=True)
            next_logits = next_logits[:, -1]
        generated = list(ids[0].tolist())
        prompt_len = ids.shape[1]
        offset = ids.shape[1]

        for _ in range(max_new_tokens):
            penalty_source = generated if penalize_prompt else generated[prompt_len:]
            banned = []
            if no_repeat_ngram_size and len(generated) >= no_repeat_ngram_size:
                n = no_repeat_ngram_size
                suffix = tuple(generated[-(n - 1):]) if n > 1 else ()
                for i in range(len(generated) - n + 1):
                    if tuple(generated[i:i + n - 1]) == suffix:
                        banned.append(generated[i + n - 1])
            if temperature > 0:
                logits = next_logits / temperature
                if repetition_penalty and repetition_penalty != 1.0:
                    for token_id in set(penalty_source):
                        score = logits[0, token_id]
                        logits[0, token_id] = score / repetition_penalty if score >= 0 \
                            else score * repetition_penalty
                for token_id in banned:
                    logits[0, token_id] = -torch.inf
                if top_k is not None:
                    k = min(top_k, logits.shape[-1])
                    top_values, _ = torch.topk(logits, k)
                    logits[logits < top_values[:, -1:]] = -torch.inf
                probs = F.softmax(logits, dim=-1)
                if top_p is not None and top_p < 1.0:
                    sorted_probs, sorted_indices = torch.sort(probs, descending=True, dim=-1)
                    cumsum = sorted_probs.cumsum(dim=-1)
                    remove = cumsum > top_p
                    remove[..., 1:] = remove[..., :-1].clone()
                    remove[..., 0] = False
                    filtered = torch.zeros_like(probs)
                    filtered.scatter_(1, sorted_indices[~remove].unsqueeze(0),
                                      sorted_probs[~remove].unsqueeze(0))
                    probs = filtered / filtered.sum(dim=-1, keepdim=True)
                next_id = torch.multinomial(probs, num_samples=1).item()
            else:
                logits = next_logits.clone()
                for token_id in banned:
                    logits[0, token_id] = -torch.inf
                next_id = logits.argmax(dim=-1).item()
            if eos_id is not None and next_id == eos_id:
                break
            generated.append(next_id)
            if on_token is not None and on_token(next_id):
                break
            next_token = torch.tensor([[next_id]], device=device, dtype=torch.long)
            next_logits, states = self._forward_hidden(next_token, mode="recurrent",
                                                       states=states, offset=offset,
                                                       return_state=True)
            next_logits = next_logits[:, -1]
            offset += 1
        return torch.tensor([generated], device=device, dtype=torch.long)
```

Autoregressive generation: when the length is greater than 1, it runs parallel mode for prefill and takes the logits of the last position; each subsequent token then takes one recurrent step while incrementing offset. Sampling supports temperature, top-k, top-p, repetition penalty, and n-gram banning, and a callback can be invoked on every token. Before 2026-10-20 the parallel path performed two extra normalizations compared with the training path, so prefill did not match the training distribution (E16); those normalizations have been removed, but the junction between prefill and recurrent decoding should still be pinned down by a numerical regression test.

```python
def _index_tables(chunk_size: int, device):
    """``causal`` / ``expo`` / ``rel`` 只依赖 chunk_size，缓存掉。

    原实现每次调用都重算 ``arange``/``sub``/``ge``/``clamp``，是 4 次无用的小
    内核发射；而本算子的成本**几乎全是发射延迟**（见下）。
    """
    key = (int(chunk_size), str(device))
    tables = _INDEX_CACHE.get(key)
    if tables is not None:
        _INDEX_CACHE.move_to_end(key)
        return tables
    rel = torch.arange(chunk_size, device=device)
    delta = rel[:, None] - rel[None, :]
    causal = delta >= 0
    expo = delta.clamp_min(0).to(torch.float32)
    tables = (causal, expo, rel.to(torch.float32))
    _INDEX_CACHE[key] = tables
    while len(_INDEX_CACHE) > _INDEX_CACHE_MAX:
        _INDEX_CACHE.popitem(last=False)          # 淘汰最久未用的
    return tables
```

Cache the three index tables that depend only on chunk_size: the causal mask, the clamped exponent, and the position vector. The original implementation recomputed arange/sub/ge/clamp on every call, which is four kernel launches of pure overhead; almost all of this operator's cost is launch latency, so caching these tables is a real, measured gain. The cache key includes the device string, avoiding incorrect reuse across devices.

```python
def _decay_tables(gamma: torch.Tensor, chunk_size: int, dtype: torch.dtype,
                  device: torch.device):
    """gamma: [H] (fp32)。返回 inner_mask [H,C,C], cross_decay [H,C],
    value_decay [H,C], chunk_decay [H]，均为 ``dtype``。

    块内掩码用**对数空间** ``exp(log γ · delta)``，这是唯一在本模型门控范围
    两端都安全的写法：

    * 因式分解的 ``γ^i · γ^-j`` 一旦需要 ``γ^-255`` 就溢出 fp32。
      ``retnet_272m_rp`` 的 GLA 门控最小到 0.668，``0.668**-255 = 1e44 > 3.4e38``
      → Inf → 前向 NaN（``torch.where`` 只丢结果，不阻止 Inf 被算出来）。
    * 朴素 ``γ ** delta`` 对 γ<1 安全（下溢到 0，那里本来就该是 0），
      但对 γ>1 的门控不成立；对数形式两端都对。

    NOTE(2026-10-10): 这个算子只有 26 万个元素却要花 **410 µs** —— 成本几乎全是
    「22 个相互依赖的小内核」的发射延迟（Windows 上约 18 µs/次）。所以这里的
    优化目标一律是**减少发射次数**，而不是减少计算量：
      * 索引张量进缓存（省 4 次发射）；
      * 三张一维表复用同一个 ``γ^j``：[H,C]：``cross = γ^j·γ``、
        ``value = flip(γ^j)``、``chunk = γ^j[-1]·γ``，
        把原来的 3 次 ``exp`` 压成 1 次。
    """
    causal, expo, relf = _index_tables(chunk_size, device)
    g = gamma.to(device=device, dtype=torch.float32)
    # γ 可以合法地取到 0（门控被训练成「完全遗忘」），此时 log(0) = -inf，
    # 而对角线 delta=0 会让 exp(-inf * 0) = exp(NaN) —— torch.where 只丢结果、
    # 不阻止 NaN 被算出来，于是整层 NaN。夹一个正下限后
    # exp(logγ·0) = 1、exp(logγ·k) 下溢到 0，正好是参考实现 gamma**delta 的
    # 语义（0**0 = 1、0**k = 0），两条路径在 γ=0 处重新等价。
    log_gamma = torch.log(g.clamp_min(torch.finfo(torch.float32).tiny))

    inner_mask = torch.exp(log_gamma[:, None, None] * expo[None])
    inner_mask = torch.where(causal, inner_mask,
                             torch.zeros((), device=device, dtype=torch.float32))

    pow1d = torch.exp(log_gamma[:, None] * relf[None, :])     # [H,C] = γ^j
    cross_decay = pow1d * g[:, None]                          # γ^(j+1)
    value_decay = pow1d.flip(-1)                              # γ^(C-1-j)
    chunk_decay = pow1d[:, -1] * g                            # γ^C

    return (inner_mask.to(dtype), cross_decay.to(dtype),
            value_decay.to(dtype), chunk_decay.to(dtype))
```

Generates four decay tables from the per-head gamma: the intra-block mask, the cross-block decay, the value decay, and the whole-block decay. The key implementation detail is that everything stays in log space: exp(log gamma * delta), because the factorized form gamma^i * gamma^-j overflows fp32 to Inf when gamma<1 and the exponent is negative, and this project has really produced a whole-layer NaN. gamma is first clamped to a tiny positive number, ensuring that gamma=0 yields 0^0=1 and 0^k=0, consistent with the semantics of the reference implementation.

### `chunkwise_batched` (L107–L192)

**00 links**: E16

```python
def chunkwise_batched(q, k, v, gamma, state, chunk_size):
    """Drop-in replacement for ``MultiScaleRetention._chunkwise_retention``.

    q, k: [B,H,L,kd]   v: [B,H,L,vd]   gamma: [H] fp32
    state: [B,H,kd,vd] or None    ->  (output [B,H,L,vd], new_state)
    """
    B, H, L, kd = q.shape
    vd = v.shape[-1]
    if L % chunk_size != 0:
        raise ValueError(f"seq_len {L} not a multiple of chunk_size {chunk_size}")
    nc = L // chunk_size
    C = chunk_size
    dev = q.device

    inner_mask, cross_decay, value_decay, chunk_decay = _decay_tables(
        gamma.to(device=dev, dtype=torch.float32), C, q.dtype, dev)

    has_state = state is not None
    if state is None:
        state = torch.zeros(B, H, kd, vd, device=dev, dtype=q.dtype)

    # [B,H,nc,C,*] views — no copy (L is contiguous)
    qr = q.view(B, H, nc, C, kd)
    kr = k.view(B, H, nc, C, kd)
    vr = v.view(B, H, nc, C, vd)

    # (1) per-chunk state contributions, one batched matmul over all chunks
    U = torch.matmul(kr.transpose(-1, -2),
                     vr * value_decay[None, :, None, :, None])   # [B,H,nc,kd,vd]

    # (2) exclusive scan -> S_prev[i] = state before chunk i
    #
    # NOTE(2026-10-10): 原来的写法是 nc 次串行 ``s = decay*s + U[:,:,i]``
    # 外加一次 ``torch.stack`` —— nc=16 时 33 次内核发射、实测 **591 µs**，
    # 而每个参与的张量只有 0.5 MB：几乎全部是发射延迟。
    #
    # 关键观察是 ``decay = chunk_decay`` 在整个循环里**是常量**（它是 [H] 的
    # 每头常数，不随 chunk 变），于是有闭式解
    #
    #     S_prev[i] = d^i · state + Σ_{j<i} d^(i-1-j) · U_j
    #
    # 这正是对 ``T[h,i,j] = d_h^(i-1-j)``（下三角）的一次批量矩阵乘：
    #
    #     S_all = T[None] @ U.reshape(B,H,nc,kd*vd)          [B,H,nc+1,kd*vd]
    #
    # 多出来的一行 i=nc 恰好就是 new_state。**所有指数非负**，因此不存在
    # §2.1 那种 ``γ^-j`` 溢出——d 再小也只是下溢到 0，那本就代表历史被忘光。
    #
    # NOTE(2026-10-10): 之前试过对数深度（Hillis-Steele）扫描把启动数从 2·nc
    # 降到 ~2·log2(nc)，**反而慢 2.8 倍**（3004 vs 1078 ms），内核数还从
    # 10116 涨到 11472 —— 因为每轮都要 ``torch.cat`` 物化一个
    # [B,H,nc,kd,vd] 张量，既贵又破坏 inductor 的融合。这里的闭式解不物化任何
    # 额外的大张量（``T`` 只有 H·(nc+1)·nc 个元素），所以是另一回事。
    #     Collected in a list and stacked: writing into a torch.empty() buffer
    #     with slice assignment makes autograd emit CopySlices and leaves the
    #     untouched-in-backward buffer as uninitialised memory.
    # 同样要夹下限：expo_t 在 (i=0, j=0) 处为 -1，clamp_min(0) 后是 0，
    # 若 log_d 是 -inf 则 -inf*0 = NaN 会留在 T 的对角线上。
    log_d = (torch.log(gamma.to(device=dev, dtype=torch.float32)
                       .clamp_min(torch.finfo(torch.float32).tiny))
             * float(chunk_size))
    idx = torch.arange(nc + 1, device=dev)
    expo_t = idx[:, None] - torch.arange(nc, device=dev)[None, :] - 1
    valid_t = expo_t >= 0
    T = torch.exp(log_d[:, None, None] * expo_t.clamp_min(0).to(torch.float32)[None])
    T = torch.where(valid_t[None], T, torch.zeros((), device=dev, dtype=torch.float32))
    T = T.to(q.dtype)                                          # [H,nc+1,nc]

    U_flat = U.reshape(B, H, nc, kd * vd)
    S_all = torch.matmul(T[None], U_flat)                      # [B,H,nc+1,kd*vd]
    if has_state:
        t_state = torch.exp(log_d[:, None] * idx.to(torch.float32)[None]).to(q.dtype)
        S_all = S_all + t_state[None, :, :, None] * state.reshape(B, H, 1, kd * vd)

    S_prev = S_all[:, :, :nc].reshape(B, H, nc, kd, vd)
    new_state = S_all[:, :, nc].reshape(B, H, kd, vd)

    # (3) inner chunk, one batched matmul
    inner = torch.matmul(
        torch.matmul(qr, kr.transpose(-1, -2)) * inner_mask[None, :, None, :, :], vr)

    # (4) cross chunk, one batched matmul
    cross = torch.matmul(qr * cross_decay[None, :, None, :, None], S_prev)

    out = (inner + cross).reshape(B, H, L, vd)
    return out, new_state
```

Batched chunkwise kernel: it splits the sequence into chunks, computes the state contribution of every chunk with a single batched matmul, then runs an exclusive scan over the closed-form lower-triangular matrix T to obtain the state preceding each chunk, and finally computes the intra-chunk and cross-chunk contributions separately. There are 5 batched matmuls in total (U, S_all, qk, inner, cross), independent of the number of chunks; the closed-form solution avoids nc serial loop iterations, which is why it is an order of magnitude faster than the reference implementation. Mathematically it is **the same function as _chunkwise_retention, equivalent down to floating-point rounding rather than bitwise identical** (measured max|delta| 1.9e-6 at gamma=0.5 and 1.5e-5 at gamma=0.99, tests/test_fast_chunkwise.py); it reads gamma only and performs no normalization at all.

    def _check_boundaries(self, sample: int = 2_000_000) -> None:
        """抽查前 sample 个 token 里是否出现 eos；没有就拒绝。

        eos id=2 由 tokenizer 固定（pad=0 / bos=1 / eos=2），见
        `scripts/prepare_pretrain_v2.py` 的构造与 `bpe_tokenizer.json`。

        if not self.shards:
            return
        per = max(1, sample // len(self.shards))
        seen = 0
        for _p, arr, _n in self.shards:

            if take <= 0:
                continue
            seg = np.asarray(arr[:take])
            seen += take
            if int((seg == 2).sum()) > 0:
                return
            if seen >= sample:
                break

            f"阶段「{self.name}」的 flat 分片里抽查 {seen:,} 个 token 没有任何 <eos>。"
            f"这条流没有文档边界，训练会让模型学会忽略远距离内容（docs/00 E12）。"
            f"用带 --add-eos 的 build_flat_corpus.py 重建；"
            f"如果你确认这是有意的，在计划里给该阶段写 require_eos: false。")

```python
    def _scan(self):
        """扫描目录，返回 (shards, starts, rows)。

        **跳过打不开的分片**：数据可能正在从外面传进来，文件被截断时
        ``np.load(mmap_mode=...)`` 会抛 ``ValueError: mmap length is greater than
        file size``。这里选择跳过而不是崩——下一轮 ``refresh()`` 会把它收进来。
        """
        width = self.seq_len + 1
        files = sorted(p for p in self.data_dir.glob("*.npy") if "val" not in p.name.lower())
        if self.exclude:
            files = [p for p in files if not p.name.startswith(self.exclude)]
        shards, starts, total = [], [], 0
        signature = []
        for p in files:
            try:
                arr = np.load(p, mmap_mode="r")
            except Exception:                                   # noqa: BLE001
                continue          # 正在写入 / 损坏，等下次 refresh
            if arr.ndim != 1:
                continue
            st = p.stat()
            n = arr.shape[0] // width
            if n == 0:
                continue
            shards.append((p, arr, n))
            starts.append(total)
            total += n
            signature.append((p.name, st.st_mtime_ns, st.st_size))
        return shards, starts, total, tuple(signature)
```

A shard that cannot be opened is skipped rather than crashing the run, because data may still be arriving from an external transfer and the next refresh will pick it up; this is the basis of "train while transferring".

    def refresh(self) -> bool:

        2026-10-20（docs/00 E19）：旧实现只比 ``len(shards)`` 与总行数，

### `_fused_forward` (L28–L48)

**00 links**: E22

```python
def _fused_forward(hidden, weight, target, w):
    """前向拆出来并禁用 Dynamo。

    分块循环里的 ``h[s:e]`` 是动态切片，Dynamo 追踪不了，会在此处图断裂并
    让整段退回 eager（实测直接卡住）。用 ``torch._dynamo.disable`` 明确告诉
    它「这段别管」，图断裂变成显式的边界而不是异常。
    """
    N, D = hidden.shape
    h = hidden.reshape(N, D)
    lse = torch.empty(N, device=hidden.device, dtype=torch.float32)
    tgt_logit = torch.empty(N, device=hidden.device, dtype=torch.float32)
    # 头部 fp32 转换**只做一次**：旧写法在循环里每块都算一遍
    # ``weight.float().t()``，0.5B 模型的 20k×1408 头每块多 112 MB 的临时拷贝。
    wf_t = weight.float().t()
    for s in range(0, N, LOGIT_CHUNK):
        e = min(s + LOGIT_CHUNK, N)
        lg = h[s:e].float() @ wf_t                               # [c, V]
        lse[s:e] = torch.logsumexp(lg, dim=-1)
        tgt_logit[s:e] = lg.gather(1, target[s:e].unsqueeze(1)).squeeze(1)
        del lg
    return lse, tgt_logit
```

Forward pass of the fused cross-entropy: it computes the logits in chunks of LOGIT_CHUNK and stores only the logsumexp of each row and the logit of the target token, never the full [N,V] matrix. Peak GPU memory therefore drops from N x V x 4 bytes to N x 4. The function is marked with torch._dynamo.disable because the dynamic slicing over chunks would break the Dynamo graph and fall back to eager.

### `_fused_backward` (L52–L69)

**00 links**: E22

```python
def _fused_backward(h, weight, target, w, grad_out, wsum):
    N, D = h.shape
    grad_h = torch.zeros_like(h)
    grad_w = torch.zeros_like(weight)
    scale = (grad_out / wsum).to(torch.float32)
    wf = weight.float()                       # 同上：整段只转一次
    wf_t = wf.t()
    for s in range(0, N, LOGIT_CHUNK):
        e = min(s + LOGIT_CHUNK, N)
        hc = h[s:e].float()
        lg = hc @ wf_t                                        # [c, V]
        p = torch.softmax(lg, dim=-1)
        p.scatter_(1, target[s:e].unsqueeze(1), -1.0)         # p - onehot
        p.mul_(w[s:e].unsqueeze(1) * scale)                   # 权重码 + 上游梯度
        grad_h[s:e] = (p @ wf).to(h.dtype)
        grad_w += (p.t() @ hc).to(weight.dtype)
        del lg, p, hc
    return grad_h, grad_w
```

The backward pass of the fused cross-entropy: it recomputes logits and softmax over the same chunks, subtracts the onehot, multiplies by the weight code and the upstream gradient, and accumulates the gradients with respect to the hidden states and the output head weights separately. The cost is one extra LM head GEMM in the backward pass; what it buys is that [N,V] never has to be resident in GPU memory at all. The weight-code semantics are fully identical to the loss in modeling.

```python
def last_loss(output_dir: Path, n: int = 5) -> list:
    """Read latest loss log entries from trainer_state.json of newest ckpt."""
    ckpts = sorted(output_dir.glob("checkpoint-*"), key=lambda p: int(p.name.split("-")[-1]))
    if not ckpts:
        return []
    st = ckpts[-1] / "trainer_state.json"
    if not st.exists():
        return []
    state = json.loads(st.read_text(encoding="utf-8"))
    hist = [e for e in state.get("log_history", []) if "loss" in e or "eval_loss" in e]
    return hist[-n:]
```

Note that it reads only the newest checkpoint: if the best checkpoint has been rotated away and deleted, this interface cannot see its history either.

          这是一条**自愈的级联**，不是死锁。

        w[: ow.shape[0], : ow.shape[1]] = ow

                torch.randn(n_new_rows, ow.shape[1], generator=gen) * NEW_ROW_INIT_STD

          ``dL/dW_newcol = 上游 x 0 = 0``，新列永远学不动。所以整段必须抬到 1.0。
        * final_norm gate=0.0：它是第二段通往 logits 的唯一出口。整段置 0 才能
          保证“生长后 logits 不变”—— embedding 的第二段会被重新随机（E03），
          若 final_norm 上半段还留着源的非零门控，那次随机就会漏进 logits。
          实测：把源 final ``gamma_new``（0.4）照搬过来，max|Δ logits| = 0.529。

        两者合起来：函数在输出端严格保真，而新参数从第 0/1 步起就有梯度。
        **代价是源模型第二段学到的门控会被丢弃**；这是有意的取舍，不是抄漏。
        """
        if src_grown:
            new_sd[new_p + ".ln_old.weight"] = old_sd[old_prefix + ".ln_old.weight"].clone()
            new_sd[new_p + ".ln_old.bias"] = old_sd[old_prefix + ".ln_old.bias"].clone()
        else:
            new_sd[new_p + ".ln_old.weight"] = old_sd[old_prefix + ".weight"].clone()
            new_sd[new_p + ".ln_old.bias"] = old_sd[old_prefix + ".bias"].clone()
        n_new = int(d_new) - int(grow_old_dim)
        new_sd[new_p + ".gamma_new"] = torch.full((n_new,), float(gate))
        new_sd[new_p + ".beta_new"] = torch.zeros(n_new)

    # 嵌入：旧列照搬；[grow_old_dim:] 一律重新随机。
    # 这一段既包含本次新增的 384 列，也包含上一次生长遗留的 256 个死列——
    # 它们必须一起复活，否则"函数保真"仍然成立，但新维度没有信号源，
    # 下游新列拿到的输入仍然是 0，梯度仍然是 0。
    gen = torch.Generator().manual_seed(1234)
    emb = torch.zeros(cfg.vocab_size, NEW_D)
    emb[:, :grow_old_dim] = old_sd["embedding.weight"][:, :grow_old_dim]
    rev = emb[:, grow_old_dim:]
    emb[:, grow_old_dim:] = torch.randn(rev.shape, generator=gen) * 0.02
    new_sd["embedding.weight"] = emb

    for i in range(NEW_L):
        p, q = f"blocks.{i}.", f"blocks.{i}."
        fill(p + "msr.q_proj.weight", q + "msr.q_proj.weight", NEW_D, NEW_D, gen)
        fill(p + "msr.k_proj.weight", q + "msr.k_proj.weight", NEW_D, NEW_D, gen)
        fill(p + "msr.v_proj.weight", q + "msr.v_proj.weight", NEW_VD, NEW_D, gen)
        fill(p + "msr.g_proj.weight", q + "msr.g_proj.weight", NEW_VD, NEW_D, gen)
        fill(p + "msr.out_proj.weight", q + "msr.out_proj.weight", NEW_D, NEW_VD, gen)
        fill(p + "ffn.0.weight", q + "ffn.0.weight", NEW_VD, NEW_D, gen)
        fill(p + "ffn.2.weight", q + "ffn.2.weight", NEW_D, NEW_VD, gen)

        # GroupNorm：按头成组拷贝，新头 weight=1 / bias=0
        gn_w = torch.ones(NEW_VD); gn_b = torch.zeros(NEW_VD)
        ow = old_sd[q + "msr.group_norm.weight"]; ob = old_sd[q + "msr.group_norm.bias"]
        assert ow.numel() == OLD_VD
        for h in range(OLD_H):
            gn_w[h * GROUP:(h + 1) * GROUP] = ow[h * GROUP:(h + 1) * GROUP]
            gn_b[h * GROUP:(h + 1) * GROUP] = ob[h * GROUP:(h + 1) * GROUP]
        new_sd[p + "msr.group_norm.weight"] = gn_w
        new_sd[p + "msr.group_norm.bias"] = gn_b

        # GLA gamma：旧头照搬（训练后已偏离公式值），新头用公式值
        new_gamma = 1.0 - torch.pow(2.0, -5.0 - torch.arange(NEW_H, dtype=torch.float32))
        new_gamma[:OLD_H] = old_sd[q + "msr.gamma"]
        new_sd[p + "msr.gamma"] = new_gamma

        # 中间层门控 = BLOCK_GATE：新维度必须能流进 q/k/v 的新列，否则新列永远零梯度
        grow_norm(p + "norm1", q + "norm1", NEW_D, gate=BLOCK_GATE)
        grow_norm(p + "norm2", q + "norm2", NEW_D, gate=BLOCK_GATE)

    # final_norm 门控 = FINAL_GATE：新维度在输出端被关掉，保证 logits 不变；
    # 它的梯度仍非零（上游经 tied lm_head 的新列回传），所以会自己长开
    grow_norm("final_norm", "final_norm", NEW_D, gate=FINAL_GATE)

    # 布局断言（P1-8）：文档写的映射必须就是真的映射，否则下一次生长会照着
    # 一段错的配方去改。检查三件事：分段数量、源段逐值继承、新增段恒为 gate。
    def _check_norm_layout(new_p: str, gate: float) -> None:
        g = new_sd[new_p + ".gamma_new"]
        b = new_sd[new_p + ".beta_new"]
        n_new = NEW_D - grow_old_dim
        if int(g.numel()) != n_new or int(b.numel()) != n_new:
            raise SystemExit(
                f"{new_p}: gamma_new/beta_new 长度 {g.numel()}/{b.numel()} "
                f"!= 期望 {n_new}（NEW_D={NEW_D}, 切点={grow_old_dim}）")
        if not torch.all(g == float(gate)):
            bad = g[g != float(gate)]
            raise SystemExit(
                f"{new_p}: 第二段 {n_new} 维门控应整段为 {gate}，"
                f"实际有 {bad.numel()} 个不等于它（如 {float(bad[0]):.4f}）")
        if not torch.all(b == 0.0):
            raise SystemExit(f"{new_p}: 第二段 beta 不是全 0")

    for i in range(NEW_L):
        _check_norm_layout(f"blocks.{i}.norm1", BLOCK_GATE)
        _check_norm_layout(f"blocks.{i}.norm2", BLOCK_GATE)
    _check_norm_layout("final_norm", FINAL_GATE)
    print(f"[layout] norm 分段布局断言通过：第二段整段 "
          f"blocks={BLOCK_GATE} / final={FINAL_GATE}（源旧门控有意不继承）",
          flush=True)

    new.load_state_dict(new_sd, strict=True)
    new.tie_weights()
    n = sum(pp.numel() for pp in new.parameters())
    # TARGET_PARAMS 是 504M 配方专用的常数；测试把维度缩小时它被置 0。
    # 旧实现仍然算 `n == 0` -> ok_n 恒 False -> 成功路径永远返回 1，
    # 测试只能写 `assert rc in (0, 1)`，于是“成功”和“参数量不符”分不开。
    if TARGET_PARAMS:
        ok_n = (n == TARGET_PARAMS)
        print(f"生长后参数量 = {n:,}  （期望 {TARGET_PARAMS:,}）  "
              f"{'✅' if ok_n else '❌ 差 ' + format(n - TARGET_PARAMS, ',')}")
    else:
        ok_n = True
        print(f"生长后参数量 = {n:,}（TARGET_PARAMS=0：跳过参数量断言，缩小配方）")

    verified = None
    if args.verify:
        x = torch.randint(1, cfg.vocab_size, (2, args.seq))
        old.eval(); new.eval()
        # NOTE: 必须传 labels —— `RetNetForCausalLM.forward` 只在 labels 非 None 时
        # 才给 `loss` 赋值，否则第 526 行 `CausalLMOutput(loss=loss, ...)` 直接
        # UnboundLocalError。（那是既有实现的小毛病，不是本脚本的问题；这里绕开它。）
        with torch.inference_mode():
            d = (old(x, labels=x).logits - new(x, labels=x).logits).abs().max().item()
        verified = d < args.tol
        print(f"函数保真校验: max|Δ logits| = {d:.3e}  容差 {args.tol:.0e}  "
              f"{'✅ OK' if verified else '❌ FAIL'}")

    if not args.verify:
        print("\n⚠️ 没加 --verify。**生长脚本不校验等于没生长**——"
              "配置文件漏搬（本项目真实踩过）会静默产出不保真的检查点。建议永远带上。")

    # ---- 可训性校验（E04）------------------------------------------------
    # 函数保真只证明"生长没改坏旧模型"，它**不能**证明"新参数能学"：
    # 一个恒零的旁支是最完美的函数保真，上面那条检查因此永远通过。
    # 这里跑 5 步真实反向，逐参数看梯度是否非零。零梯度 = 这个参数
    # 从第 0 步起就没有任何信号，训练多少步都不会变。
    #
    # 为什么是 5 步而不是 1 步：新维度是"级联自愈"的——
    #   第 0 步：只有 embedding 新列、以及读新输入的列有梯度；
    #   第 1 步：新列变非零，读它们的下游列开始有梯度；
    #   第 2 步：新单元的输出投影（新行）拿到梯度。
    # 5 步足够走完这条链；仍为零的参数就是真的死了。
    print(f"[trainable] 跑 5 步反向，seq={args.seq}，统计零梯度参数 ...", flush=True)
    new.train()
    opt = torch.optim.AdamW(new.parameters(), lr=1e-4)
    probe = torch.randint(1, cfg.vocab_size, (2, args.seq))
    for _ in range(5):
        opt.zero_grad(set_to_none=True)
        out = new(probe, labels=probe)
        out.loss.backward()
        opt.step()
    dead = [n for n, p in new.named_parameters()
            if p.grad is None or p.grad.abs().max().item() == 0.0]
    trainable = not dead
    if dead:
        print(f"[trainable] ❌ {len(dead)} 个参数梯度恒 0：")
        for name in dead[:12]:
            print("    ", name)
    else:
        print("[trainable] ✅ 全部参数梯度非零")

    # **两道校验都过才落盘**：只保真但不可训的检查点，
    # 静默产出的就是 v21 那种"67% 参数是 0"的模型。
    if verified is False or not trainable:
        print("❌ 校验未通过 —— 拒绝保存。先修映射/初始化，别拿这个检查点训练。")
        return 2

    new.save_pretrained(args.dst, safe_serialization=True)
    print(f"saved -> {args.dst}")
    return 0 if ok_n else 1
```

Main width-growth flow: validate the source model's shapes, inherit the original normalization split point and the non-weight configuration, construct the new model, map the weights via fill/grow_norm, validate the parameter count, run the two checks for functional fidelity and trainability, and finally write to disk. E01-E04 all occur in this function; after the fix the new rows are random, the new columns are zeroed, the intermediate-layer gates are 1 and the final_norm gate is 0, and a new check has been added that runs 5 backward steps and inspects the gradient of every parameter.

see [07][08][09][10][11][12][13][14]

### `main.fill` (L157–L178)

**00 links**: E01, E04

```python
    def fill(p, old_key, out_d, in_d, gen):
        """旧权重放左上角；新**列**置 0（块内隔离），新**行**随机（让新单元有输出）。

        为什么是"列 0 行随机"，而不是全 0 或全随机：

        * 新列若随机，它会立刻改变旧维度的输出，函数不再保真，且无法用任何
          门控挡住（扰动已经进了旧维度）。所以新列必须是 0。
        * 新行若全 0，新单元（新头、新隐藏单元）的输出恒为 0，下游那些
          "读新单元"的列拿到的输入是 0，梯度 `上游 x 0 = 0`，整条新子网
          永远学不动——v21 的 338M 死参数就是这么来的。
        * 新行随机后：新单元有非零输出 -> 下游新列拿到非零输入 -> 新列在
          第 1 步就有梯度；新列变非零后，新行在第 2 步拿到梯度。
          这是一条**自愈的级联**，不是死锁。
        """
        w = torch.zeros(out_d, in_d)
        ow = old_sd[old_key]
        w[: ow.shape[0], : ow.shape[1]] = ow
        n_new_rows = out_d - ow.shape[0]
        if n_new_rows > 0:
            w[ow.shape[0]:, : ow.shape[1]] = \
                torch.randn(n_new_rows, ow.shape[1], generator=gen) * NEW_ROW_INIT_STD
        new_sd[p] = w
```

Places the old weights into the top-left corner of the new matrix and decides the initial values of the added rows and columns. New columns must be zeroed: otherwise they would immediately change the output of the old dimensions, the function would no longer be faithful, and that perturbation could not be blocked by any gate. New rows must be random: all zeros would make the new units output identically zero, the downstream columns reading them would receive zero input, and the gradient would be identically zero as well, which is exactly where the 3.38e8 dead parameters of the previous round came from. Random new rows let the new units produce output first, so the downstream columns receive a gradient at step 1, and once the new columns become nonzero the new rows receive a gradient at step 2, forming a self-healing cascade.

see [07][08][09]

### `main.grow_norm` (L180–L204)

**00 links**: E02, E05

```python
    def grow_norm(new_p, old_prefix, d_new, gate):
        """两段式 norm：旧段照搬，**第二段整段**（含源里已有的那一截）重设为 gate。

        这里**故意不**继承源模型第二段的 ``gamma_new[:n_src_new]``，理由分两边：

        * 中间层 gate=1.0：新维度要进入 q/k/v 的**新列**，而新列初始为 0；
          若门控也沿用源值（v21 里恰好是 0，E02 的 bug），则新列乘到的输入恒 0，
          ``dL/dW_newcol = 上游 x 0 = 0``，新列永远学不动。所以整段必须抬到 1.0。
        * final_norm gate=0.0：它是第二段通往 logits 的唯一出口。整段置 0 才能
          保证“生长后 logits 不变”—— embedding 的第二段会被重新随机（E03），
          若 final_norm 上半段还留着源的非零门控，那次随机就会漏进 logits。
          实测：把源 final ``gamma_new``（0.4）照搬过来，max|Δ logits| = 0.529。

        两者合起来：函数在输出端严格保真，而新参数从第 0/1 步起就有梯度。
        **代价是源模型第二段学到的门控会被丢弃**；这是有意的取舍，不是抄漏。
        """
        if src_grown:
            new_sd[new_p + ".ln_old.weight"] = old_sd[old_prefix + ".ln_old.weight"].clone()
            new_sd[new_p + ".ln_old.bias"] = old_sd[old_prefix + ".ln_old.bias"].clone()
        else:
            new_sd[new_p + ".ln_old.weight"] = old_sd[old_prefix + ".weight"].clone()
            new_sd[new_p + ".ln_old.bias"] = old_sd[old_prefix + ".bias"].clone()
        n_new = int(d_new) - int(grow_old_dim)
        new_sd[new_p + ".gamma_new"] = torch.full((n_new,), float(gate))
        new_sd[new_p + ".beta_new"] = torch.zeros(n_new)
```

Resets the new-segment gates of the two-part norm. The intermediate layers must be 1: the new dimensions must be able to flow into the new columns of q/k/v, otherwise those new columns receive identically zero input and an identically zero gradient. final_norm must be 0: it is the only exit from the new dimensions to the logits, and zeroing it is what keeps the logits unchanged after growth; its gradient comes from the upstream logits multiplied by the new dimensions, and the upstream path returns through the new columns of the tied lm_head (random, hence nonzero), so it learns a nonzero value from the very first step. The weights and bias of the old segment ln_old are inherited unchanged, which keeps the normalization statistics of the old dimensions exactly as they were.

see [08][09][13]
